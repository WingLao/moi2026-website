## Description · 題目說明

:::en
A staircase has N steps. Each move climbs 1 or 2 steps. Starting from the ground (step 0), how many different ways are there to reach step N?
:::

:::zh
一段樓梯共有 N 級，每次可以走 1 級或 2 級。從地面（第 0 級）出發，走到第 N 級共有多少種不同的走法？
:::

## Input · 輸入格式

:::en
One line with a positive integer N (1 ≤ N ≤ 30).
:::

:::zh
一行，一個正整數 N（1 ≤ N ≤ 30）。
:::

## Output · 輸出格式

:::en
One line: the number of ways.
:::

:::zh
一行：走法的數量。
:::

## Sample Input · 範例輸入

```text
1
```

## Sample Output · 範例輸出

```text
1
```

## Explanation · 說明

:::en
For example, the ways to reach step 5 are 11111, 1112, 1121, 1211, 2111, 122, 212 and 221 — 8 ways.
:::

:::zh
例如走到第 5 級的走法有 11111、1112、1121、1211、2111、122、212、221，共 8 種。
:::
