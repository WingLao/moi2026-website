## Description · 題目說明

:::zh
小 S 的詞典裡有 $n$ 個兩兩不同的、長度均為 $m$ 的單詞 $w_1,w_2,\cdots,w_n$。每個單詞都是一個小寫字母構成的字串。

小 S 可以做以下操作任意多次（可以不做）：選擇詞典中的任意一個單詞，交換其中任意兩個字元。

對於每個 $1 \le i \le n$，小 S 想知道，是否可以透過以上操作得到新的 $n$ 個單詞 $w'_1,w'_2,\cdots , w'_n$，使得對於每個 $j \neq i$，$w'_i$ 的字典序比 $w'_j$ 都要小。**對於 $n=1$ 的情況，我們約定：上述性質是自然成立的。**

對於兩個同樣長度的字串 $s = s_1s_2\cdots s_L$ 和 $t = t_1t_2 \cdots t_L$，稱字串 $s$ 字典序小於字串 $t$，當且僅當以下條件成立：存在位置 $i$，在第 $i$ 個字元之前 $s$ 和 $t$ 都相同，而且 $s_i < t_i$，即小寫字母 $s_i$ 在英文字母順序中先於 $t_i$。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含兩個正整數 $n$ 和 $m$，分別表示單詞個數和單詞長度。

接下來 $n$ 行，每行包含一個長度為 $m$ 的小寫字母字串 $w_i$， 表示一個單詞。
:::

## Output · 輸出格式

:::zh
輸出一行，其中包含一個長度為 $n$ 的 `01` 字串 $a$；對於 $1 \le i \le n$，如果題目描述中的性質成立，則 $a_i =$ `1`，否則 $a_i =$ `0`。
:::

## Sample Input · 範例輸入

```text
4 7
abandon
bananaa
baannaa
notnotn
```

## Sample Output · 範例輸出

```text
1110
```

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

- 不做任何操作，第一個單詞字典序最小，因此輸出第一個字元為 `1`；
- 交換 `bananaa` 的前兩個字元以及 `abandon` 的第三個和第六個字元，得到 `abondan`, `abnanaa`, `baannaa`, `notnotn`，此時第二個單詞字典序最小，因此輸出第二個字元為 `1`；
- 交換 `baannaa` 的第一個和最後一個字元得到 `aaannab`，其餘字串不變，此時第三個單詞字典序最小，因此輸出第三個字元為 `1`；
- 無論如何操作，第四個單詞不會小於第二個單詞，因此輸出第四個字元為 `0`。

**【樣例解釋 #2】**

該組樣例滿足測試點 $4$ 的限制。

**【樣例解釋 #3】**

該組樣例滿足測試點 $7$ 的限制。

**【樣例解釋 #4】**

該組樣例滿足測試點 $10$ 的限制。

**【資料範圍】**

對於所有測試資料，保證：$1 \le n \le 3000$，$1 \le m \le 3000$，$w_i$ 為長度為 $m$ 的小寫字母字串且兩兩不同。

| 測試點編號 | $n\leq$ | $m\leq$ |
| :----------: | :----------: | :----------: |
| $1$ | $1$ | $1$ |
| $2\sim 4$ | $26$ | $1$ |
| $5\sim 7$ | $15$ | $2$ |

| $9$ | $10^3$ | $10^3$ |
| $10$ | $3000$ | $3000$ |
