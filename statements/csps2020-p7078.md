## Description · 題目說明

:::en
There are $n$ snakes numbered $1, 2, \ldots , n$; snake $i$ has stamina $a_i$. Snake $x$ is stronger than snake $y$ if $a_x > a_y$, or $a_x = a_y$ and $x > y$.

The snakes duel in rounds. In each round the strongest snake chooses whether to eat the weakest snake:

1. If it eats, its stamina decreases by the weakest snake's stamina, the weakest snake is removed, and the next round starts.
2. If it does not eat, the duel ends immediately.

Each snake wants to eat as many snakes as possible **without being eaten itself** (a snake never eats itself). Assuming all snakes play perfectly, how many snakes remain at the end?

There are several test groups: the first gives all staminas; each later group modifies some staminas of the previous group.
:::

:::zh
草原上有 $n$ 條蛇，編號分別為 $1, 2, \ldots , n$。初始時每條蛇有一個體力值 $a_i$，我們稱編號為 $x$ 的蛇實力比編號為 $y$ 的蛇強當且僅當它們當前的體力值滿足 $a_x > a_y$，或者 $a_x = a_y$ 且 $x > y$。

接下來這些蛇將進行決鬥，決鬥將持續若干輪，每一輪實力最強的蛇擁有選擇權，可以選擇吃或者不吃掉實力最弱的蛇：

1. 如果選擇吃，那麼實力最強的蛇的體力值將減去實力最弱的蛇的體力值，實力最弱的蛇被吃掉，退出接下來的決鬥。之後開始下一輪決鬥。
2. 如果選擇不吃，決鬥立刻結束。

每條蛇希望在自己不被吃的前提下在決鬥中儘可能多吃別的蛇（顯然，蛇不會選擇吃自己）。

現在假設每條蛇都足夠聰明，請你求出決鬥結束後會剩幾條蛇。

本題有多組資料，對於第一組資料，每條蛇體力會全部由輸入給出，之後的每一組資料，會相對於上一組的資料，修改一部分蛇的體力作為新的輸入。
:::

## Input · 輸入格式

:::en
Line 1: a positive integer $T$, the number of groups.

Group 1: a positive integer $n$, then $n$ non-negative integers $a_i$.

Groups 2 to $T$: a non-negative integer $k$, the number of changes, then $2k$ integers forming pairs $(x,y)$: set $a_x$ to $y$, in order (a position may change several times; the last change counts).
:::

:::zh
第一行一個正整數 $T$，表示資料組數。  
接下來有 $T$ 組資料，對於第一組資料，第一行一個正整數 $n$，第二行 $n$ 個非負整數表示 $a_i$。  
對於第二組到第 $T$ 組資料，每組資料：  
第一行第一個非負整數 $k$ 表示體力修改的蛇的個數。  
第二行 $2k$ 個整數，每兩個整陣列成一個二元組 $(x,y)$，表示依次將 $a_x$ 的值改為 $y$。一個位置可能被修改多次，以最後一次修改為準。
:::

## Output · 輸出格式

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 #1 解釋】**

第一組資料，第一輪中 $3$ 號蛇最強，$1$ 號蛇最弱。若 $3$ 號蛇選擇吃，那麼它將在第二輪被 $2$ 號蛇吃掉。因此 $3$ 號蛇第一輪選擇不吃，$3$ 條蛇都將存活。

對於第二組資料，$3$ 條蛇體力變為 $5, 6, 25$。第一輪中 $3$ 號蛇最強，$1$ 號蛇最弱，若它選擇吃，那麼 $3$ 號蛇體力值變為 $20$，在第二輪中依然是最強蛇並能吃掉 $2$ 號蛇，因此 $3$ 號蛇會選擇兩輪都吃，最終只有 $1$ 條蛇存活。

**【資料範圍】**

對於 $20 \%$ 的資料，$n = 3$。  
對於 $40 \%$ 的資料，$n \le 10$。  
對於 $55 \%$ 的資料，$n \le 2000$。  
對於 $70\%$ 的資料，$n \le 5 \times {10}^4$。  
對於 $100\%$ 的資料：$3 \le n \le {10}^6$，$1 \le T \le 10$，$0 \le k \le {10}^5$，$0 \le a_i, y \le 10^9$。保證每組資料（包括所有修改完成後的）的 $a_i$ 以不降順序排列。
:::
