## Description · 題目說明

:::zh
小 C 學習完了字串匹配的相關內容，現在他正在做一道習題。

對於一個字串 $S$，題目要求他找到 $S$ 的所有具有下列形式的拆分方案數：

$S = ABC$，$S = ABABC$，$S = ABAB \ldots ABC$，其中 $A$，$B$，$C$ 均是非空字串，且 $A$ 中出現奇數次的字元數量不超過 $C$ 中出現奇數次的字元數量。

更具體地，我們可以定義 $AB$ 表示兩個字串 $A$，$B$ 相連線，例如 $A = \texttt{aab}$，$B = \texttt{ab}$，則 $AB = \texttt{aabab}$。

並遞迴地定義 $A^1=A$，$A^n = A^{n - 1} A$（$n \ge 2$ 且為正整數）。例如 $A = \texttt{abb}$，則 $A^3=\texttt{abbabbabb}$。

則小 C 的習題是求 $S = {(AB)}^iC$ 的方案數，其中 $F(A) \le F(C)$，$F(S)$ 表示字串 $S$ 中出現奇數次的字元的數量。兩種方案不同當且僅當拆分出的 $A$、$B$、$C$ 中有至少一個字串不同。

小 C 並不會做這道題，只好向你求助，請你幫幫他。
:::

## Input · 輸入格式

:::zh

每組資料僅一行一個字串 $S$，意義見題目描述。$S$ 僅由英文小寫字母構成。

## Notes and Constraints · 說明與數據範圍

**【樣例 #1 解釋】**

對於第一組資料，所有的方案為

1. $A=\texttt{n}$，$B=\texttt{nr}$，$C=\texttt{nnr}$。
2. $A=\texttt{n}$，$B=\texttt{nrn}$，$C=\texttt{nr}$。
3. $A=\texttt{n}$，$B=\texttt{nrnn}$，$C=\texttt{r}$。
4. $A=\texttt{nn}$，$B=\texttt{r}$，$C=\texttt{nnr}$。
5. $A=\texttt{nn}$，$B=\texttt{rn}$，$C=\texttt{nr}$。
6. $A=\texttt{nn}$，$B=\texttt{rnn}$，$C=\texttt{r}$。
7. $A=\texttt{nnr}$，$B=\texttt{n}$，$C=\texttt{nr}$。
8. $A=\texttt{nnr}$，$B=\texttt{nn}$，$C=\texttt{r}$。
