## Description · 題目說明

:::zh
小 R 有一個長度為 $n$ 的非負整數序列 $a_1, a_2, \dots, a_n$。定義一個區間 $[l, r]$ ($1 \leq l \leq r \leq n$) 的權值為 $a_l, a_{l+1}, \dots, a_r$ 的二進位制按位異或和，即 $a_l \oplus a_{l+1} \oplus \dots \oplus a_r$，其中 $\oplus$ 表示二進位制按位異或。

小 X 給了小 R 一個非負整數 $k$。小 X 希望小 R 選擇序列中儘可能多的**不相交**的區間，使得每個區間的權值均為 $k$。兩個區間 $[l_1, r_1], [l_2, r_2]$ 相交當且僅當兩個區間同時包含至少一個相同的下標，即存在 $1 \leq i \leq n$ 使得 $l_1 \leq i \leq r_1$ 且 $l_2 \leq i \leq r_2$。

例如，對於序列 $[2, 1, 0, 3]$，若 $k = 2$，則小 R 可以選擇區間 $[1, 1]$ 和區間 $[2, 4]$，權值分別為 $2$ 和 $1 \oplus 0 \oplus 3 = 2$；若 $k = 3$，則小 R 可以選擇區間 $[1, 2]$ 和區間 $[4, 4]$，權值分別為 $1 \oplus 2 = 3$ 和 $3$。

你需要幫助小 R 求出他能選出的區間數量的最大值。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含兩個非負整數 $n, k$，分別表示小 R 的序列長度和小 X 給小 R 的非負整數。

輸入的第二行包含 $n$ 個非負整數 $a_1, a_2, \dots, a_n$，表示小 R 的序列。
:::

## Output · 輸出格式

:::zh
輸出一行一個非負整數，表示小 R 能選出的區間數量的最大值。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
### 【樣例 1 解釋】

小 R 可以選擇區間 $[1, 1]$ 和區間 $[2, 4]$，異或和分別為 $2$ 和 $1 \oplus 0 \oplus 3 = 2$。可以證明，小 R 能選出的區間數量的最大值為 $2$。

### 【樣例 2 解釋】

小 R 可以選擇區間 $[1, 2]$ 和區間 $[4, 4]$，異或和分別為 $1 \oplus 2 = 3$ 和 $3$。可以證明，小 R 能選出的區間數量的最大值為 $2$。

### 【樣例 3 解釋】

小 R 可以選擇區間 $[3, 3]$，異或和為 $0$。可以證明，小 R 能選出的區間數量的最大值為 $1$。注意：小 R 不能同時選擇區間 $[3, 3]$ 和區間 $[1, 4]$，因為這兩個區間同時包含下標 $3$。
