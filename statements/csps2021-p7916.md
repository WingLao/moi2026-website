## Description · 題目說明

:::zh
給定一個平面上 $n$ 條水平直線和 $m$ 條垂直直線，它們相交形成 $n$ 行 $m$ 列的網格，從上到下第 $r$ 條水平直線和從左到右第 $c$ 條垂直直線之間的交點稱為格點 $(r, c)$。網格中任意兩個水平或垂直相鄰的格點之間的線段稱為一條邊，每條邊有一個非負整數邊權。

進行 $T$ 次詢問，每次詢問形式如下：

給出 $k$（$T$ 次詢問的 $k$ 可能不同）個附加點，每個附加點位於一條從網格邊緣向外出發的射線上。所有從網格邊緣向外出發的射線按左上-右上-右下-左下-左上的順序依次編號為 $1$ 到 $2 n + 2 m$，如下圖：

![](https://cdn.luogu.com.cn/upload/image_hosting/iwajnac8.png)

對於每次詢問，不同附加點所在的射線互不相同。每個附加點和最近的格點之間的線段也稱為一條邊，也有非負整數邊權（注意，在角上的格點有可能和兩個附加點同時相連）。

給定每個附加點的顏色（黑色或者白色），請你將網格內每個格點的顏色染成黑白二者之一，並使得所有兩端顏色不同的邊的邊權和最小。請輸出這個最小的邊權和。
:::

## Input · 輸入格式

:::zh
第一行，三個正整數 $n, m, T$，分別表示水平、垂直直線的數量，以及詢問次數。

接下來 $n - 1$ 行，每行 $m$ 個非負整數。其中第 $i$ 行的第 $j$ 個非負整數 ${x 1}_{i, j}$ 表示 $(i, j)$ 和 $(i + 1, j)$ 間的邊權。

接下來 $n$ 行，每行 $m - 1$ 個非負整數。其中第 $i$ 行的第 $j$ 個非負整數 ${x 2}_{i, j}$ 表示 $(i, j)$ 和 $(i, j + 1)$ 間的邊權。

接下來依次輸入 $T$ 組詢問。第 $i$ 組詢問開頭為一行一個正整數 $k_i$ 表示這次詢問附加點的總數。接下來 $k_i$ 行每行三個非負整數。其中第 $j$ 行依次為 ${x 3}_{i, j}, p_{i, j}, t_{i, j}$ 表示第 $j$ 個附加點和相鄰格點之間的邊權、所在的射線編號以及附加點顏色（$0$ 為白色，$1$ 為黑色）。保證同一組詢問內 $p_{i, j}$ 互不相同。

每行的多個整數由空格分隔。
:::

## Output · 輸出格式

:::zh
輸出 $T$ 行，第 $i$ 行輸出一個非負整數，表示第 $i$ 次詢問染色之後兩端顏色不同的邊權和的最小值。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

最優方案：$(1, 3), (1, 2), (2, 3)$ 為黑色；$(1, 1), (2, 1), (2, 2)$ 為白色。

**【資料範圍】**

| 測試點編號 | $n, m \le$ | $k_i \le$ |
|:-:|:-:|:-:|
| $1 \sim 2$ | $5$ | $50$ |
| $3 \sim 5$ | $18$ | $2$ |
| $6 \sim 8$ | $18$ | $50$ |
| $9 \sim 10$ | $100$ | $2$ |
| $11 \sim 12$ | $100$ | $50$ |
| $13 \sim 16$ | $500$ | $2$ |
| $17 \sim 20$ | $500$ | $50$ |

對於所有資料，$2 \le n, m \le 500$，$1 \le T \le 50$，$1 \le k_i \le \min \{ 2 (n + m), 50 \}$，$1 \le \sum_{i = 1}^{T} k_i \le 50$，$0 \le x \le {10}^6$，$1 \le p \le 2 (n + m)$，$t \in \{ 0, 1 \}$。

保證對於每個 $i \in [1, T]$，$p_{i, j}$ 互不相同。
