## Description · 題目說明

:::zh
小 S 想要舉辦一場擂臺遊戲，如果共有 $2^k$ 名選手參加，那麼遊戲分為 $k$ 輪進行：

- 第一輪編號為 $1, 2$ 的選手進行一次對局，編號為 $3, 4$ 的選手進行一次對局，以此類推，編號為 $2^k - 1, 2^k$ 的選手進行一次對局。
- 第二輪在只保留第一輪的勝者的前提下，相鄰的兩位依次進行一場對局。
- 以此類推，第 $k - 1$ 輪在只保留第 $k - 2$ 輪的 $4$ 位勝者的前提下，前兩位、後兩位分別進行對局，也就是所謂的半決賽。
- 第 $k$ 輪即為半決賽兩位勝者的決賽。

確定了遊戲晉級的規則後，小 S 將比賽的規則設定為了擂臺賽。具體而言，每位選手都有一個能力值 $a_1, a_2, \dots , a_{2^k}$，能力值為 $[0,2^{31}-1]$ 之內的整數。對於每場比賽，會先抽籤決定一個數 $0/1$，我們將第 $R$ 輪的第 $G$ 場比賽抽到的數記為 $d_{R,G}$。抽到 $0$ 則表示編號小的選手為擂主，抽到 $1$ 則表示編號大的選手為擂主。擂主獲勝當且僅當他的能力值 $a\geq R$。也就是說，遊戲的勝負只取決於**擂主的能力值**與**當前比賽是第幾輪**的大小關係，**與另一位的能力值無關**。

現在，小 S 先後陸續收到了 $n$ 位選手的報名資訊，他們分別告知了小 S 自己的能力值。小 S 會按照報名的先後順序對選手進行編號為 $1, 2, \dots, n$。小 S 關心的是，補充**儘量少**的選手使總人數為 $2$ 的整次冪，且所有選手進行一次完整的擂臺遊戲後，所有可能成為總冠軍的選手的**編號之和**是多少。

形式化地，設 $k$ 是最小的非負整數使得 $2^k\geq n$，那麼應當補充 $(2^k-n)$ 名選手，且補充的選手的能力值可以任取 $[0,2^{31}-1]$ 之內的整數。**如果補充的選手有可能取勝，也應當計入答案中**。

當然小 S 覺得這個問題還是太簡單了，所以他給了你 $m$ 個詢問 $c_1,c_2,\dots,c_m$。小 S 希望你幫忙對於每個 $c_i$ 求出，在只收到前 $c_i$ 位選手的報名資訊時，這個問題的答案是多少。
:::

## Input · 輸入格式

:::zh
**本題的測試點包含有多組測試資料。** 但不同測試資料只是透過修改 $a_1, a_2, \dots , a_n$ 得到，其他內容均保持不變，請參考以下格式。其中 $\oplus$ 代表異或運算子，$a \bmod b$ 代表 $a$ 除以 $b$ 的餘數。

輸入的第一行包含兩個正整數 $n, m$，表示報名的選手數量和詢問的數量。

輸入的第二行包含 $n$ 個非負整數 $a'_1,a'_2,\dots,a'_n$，這列數將用來計算真正的能力值。

輸入的第三行包含 $m$ 個正整數 $c_1, c_2, \dots , c_m$，表示詢問。

設 $K$ 是使得 $2^K \geq n$ 的最小的非負整數，接下來的 $K$ 行當中，第 $R$ 行包含 $2^{K-R}$ 個數（無空格），其中第 $G$ 個數表示第 $R$ 輪的第 $G$ 場比賽抽籤得到的 $d_{R,G}=0/1$。

注意，由於詢問只是將人數湊齊到 $2^k\geq c_i$，這裡的 $k\leq K$，因此你未必會用到全部的輸入值。

接下來一行包含一個正整數 $T$，表示有 $T$ 組測試資料。

接下來共 $T$ 行，每行描述一組資料，包含 $4$ 個非負整數 $X_0,X_1,X_2,X_3$，該組資料的能力值 $a_i=a'_i \oplus X_{i\bmod 4}$，其中 $1\leq i\leq n$。
:::

## Output · 輸出格式

:::zh
共輸出 $T$ 行，對於每組資料，設 $A_i$ 為第 $i$（$1 \leq i \leq m$）組詢問的答案，你只需要輸出一行包含一個整數，表示 $(1\times A_1) \oplus (2\times A_2) \oplus \dots \oplus (m\times A_m)$ 的結果。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

共有 $T = 4$ 組資料，這裡只解釋第一組。$5$ 名選手的真實能力值為 $[1, 0, 0, 2, 1]$。$5$ 組詢問分別是對長度為 $5, 4, 1, 2, 3$ 的字首進行的。

1. 對於長度為 $1$ 的字首，由於只有 $1$ 號一個人，因此答案為 $1$。
2. 對於長度為 $2$ 的字首，由於 $2$ 個人已經是 $2$ 的冪次，因此不需要進行擴充。根據抽籤 $d_{1,1} = 1$ 可知 $2$ 號為擂主，由於 $a_2 < 1$，因此 $1$ 號獲勝，答案為 $1$。
3. 對於長度為 $3$ 的字首，首先 $1$ 號、$2$ 號比賽是 $1$ 號獲勝（因為 $d_{1,1} = 1$，故 $2$ 號為擂主，$a_2 < 1$），然後雖然 $4$ 號能力值還不知道，但 $3$ 號、$4$ 號比賽一定是 $4$ 號獲勝（因為 $d_{1,2} = 0$，故 $3$ 號為擂主，$a_3 < 1$），而決賽 $1$ 號、$4$ 號誰獲勝都有可能（因為 $d_{2,1} = 1$，故 $4$ 號為擂主，如果 $a_4 < 2$ 則 $1$ 號獲勝，$a_4 \geq 2$ 則 $4$ 號獲勝）。綜上所述，答案為 $1 + 4 = 5$。
4. 對於長度為 $4$ 的字首，我們根據上一條的分析得知，由於 $a_4 \geq 2$，所以決賽獲勝的是 $4$ 號。
5. 對於長度為 $5$ 的字首，可以證明，可能獲勝的選手包括 $4$ 號、$7$ 號、$8$ 號，答案為 $19$。

因此，該組測試資料的答案為 $(1 \times 19) \oplus (2 \times 4) \oplus (3 \times 1) \oplus (4 \times 1) \oplus (5 \times 5) = 5$。
