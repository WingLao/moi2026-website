## Description · 題目說明

:::zh
遊戲在一張長 $n$ 行寬 $m$ 列的網格形棋盤上進行，棋子落在網格的交叉點上，我們不妨記左上角的交叉點的座標為 $(1,1)$，右下角的交叉點座標為 $(n,m)$。

棋子分為黑白兩色，對局雙方各執一方棋子。

每個棋子除了顏色以外還有等級，不妨設 $\mathit{col}_i$ 為棋子 $i$ 的顏色，$\mathit{lv}_i$ 為棋子 $i$ 的等級。另外，棋盤上的網格線共有 $4$ 種狀態，對於第 $i$ 條網格線，設其狀態為 $\mathit{opt}_i$。

輪到每方下棋時，他可以選擇棋盤上的一個己方棋子沿網格線進行移動到另一個交叉點，稱為走子。形式化定義走子的過程如下：選擇一個座標序列 $(x_0,y_0),(x_1,y_1),\ldots,(x_k,y_k)$，其中 $k$ 是任意選定的正整數，$(x_0,y_0)$ 是棋子初始的位置，$(x_k,y_k)$ 是棋子最終走到的位置，需要滿足：

- 對於任意 $i=0,1,\ldots,k-1$，座標 $(x_i,y_i)$ 和 $(x_{i+1},y_{i+1})$ 之間必須有網格線直接相連，也就是說**走子必須沿著網格線走**；
- 對於任意 $i\not=j$，必須有 $(x_i,y_i)\ne(x_j,y_j)$，也就是說走子過程中不能經過重複位置，特別地 $(x_0,y_0)\ne(x_k,y_k)$，也就是說**不能原地不動（或走回原地）**；
- 對於任意 $i=1,\ldots,k-1$，座標 $(x_i,y_i)$ 上必須沒有棋子，也就是說**走子時不能越過已有的棋子**；
- 若 $(x_k,y_k)$ 上沒有棋子，稱為普通走子，否則稱為吃子。在吃子過程中，設正在走的棋子顏色為 $\mathit{col}_1$，等級為 $\mathit{lv}_1$，被吃的棋子顏色為 $\mathit{col}_2$，等級為 $\mathit{lv}_2$，則必須滿足 $\mathit{col}_1\ne\mathit{col}_2,\mathit{lv}_1\geq\mathit{lv}_2$，換句話說**只能吃與自己顏色不同，且等級不高於自己等級的棋子**。

需要注意的是，由上述定義可以得出，不允許棋子在吃子後繼續向前走。

網格線的狀態含義如下所述：

- 如果 $\mathit{opt}_i=0$，代表此路不通，走子時不能經過這條網格線；
- 如果 $\mathit{opt}_i=1$，代表這條網格線是一條“普通道路”，每次走子時棋子最多隻能經過 $1$ 條普通道路。
- 如果 $\mathit{opt}_i=2$，代表這條網格線是一條“直行道路”，每次走子時棋子可以經過任意條直行道路，但只能**一直沿橫向或一直沿縱向走，不能轉彎**。如沿直行道路從 $(1,1)$ 經過 $(1,2)$ 走到 $(1,3)$ 是可以的，但是從 $(1,1)$ 經過 $(1,2)$ 走到 $(2,2)$ 不行。
- 如果 $\mathit{opt}_i=3$，代表這條網格線是一條“互通道路”，每次走子時棋子可以經過任意條互通道路，且中途可任意轉彎。

同時規定在一次走子過程中，**棋子經過的網格線的狀態必須全部相同**，比如從 $(1,1)$ 經過直行道路走到 $(1,2)$ 再經過互通道路走到 $(1,3)$ 是不允許的。

至於如何判斷勝負等其它細節，與本題無關，故略去。

小 z 和小 c 開發出這款棋類遊戲後，為了提升水平，想了一個訓練的策略：一開始棋盤是空的，然後小 c 會每次往棋盤的某個空交叉點上放一枚棋子，小 z 需要快速計算出：若選擇這枚新放上的棋子進行一次走子，棋盤上一共有多少個位置是能被走到的？注意：因為這只是思維訓練，他們並不會真的走這枚棋子。

可憐的小 z 發現他的計算力不足以算出這個問題，只好向你求助。
:::

## Input · 輸入格式

:::zh
每個測試點由多組資料組成。

第一行：一個正整數 $T$ 表示資料組數。

對於每組資料：

第一行：三個正整數 $n, m, q$，分別表示棋盤的行數、列數和遊戲的輪數。

接下來 $n$ 行，每行為一個長 $m - 1$ 的字串，每個字元為 $\texttt{0}$、$\texttt{1}$、$\texttt{2}$、$\texttt{3}$ 中的一個，第 $i$ 行第 $j$ 個字元表示交叉點 $(i, j)$ 連向交叉點 $(i, j + 1)$ 的網格線狀態。 

接下來 $n - 1$ 行，每行為一個長 $m$ 的字串，每個字元為 $\texttt{0}$、$\texttt{1}$、$\texttt{2}$、$\texttt{3}$ 中的一個，第 $i$ 行第 $j$ 個字元表示交叉點 $(i, j)$ 連向交叉點 $(i + 1, j)$ 的網格線狀態。

接下來 $q$ 行，每行 $4$ 個非負整數 $\mathit{col}_i , \mathit{lv}_i , x_i , y_i$，表示在第 $i$ 輪有一枚顏色為 $\mathit{col}_i$，等級為 $\mathit{lv}_i$ 的棋子放在了交叉點 $(x_i , y_i)$ 上。其中 $\mathit{col}_i = 0$ 表示黑子，$\mathit{col}_i = 1$ 表示白子。保證之前交叉點 $(x_i , y_i)$ 上沒有棋子。
:::

## Output · 輸出格式

:::zh
對於每組資料輸出 $q$ 行，每行一個非負整數，表示第 $i$ 枚棋子放置後能走到的交叉點數量。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

放置棋子 $1$ 後，它能走到的位置為 $(2, 1),(2, 2),(3, 2),(3, 3)$。

放置棋子 $2$ 後，它能走到的位置為 $(2, 2),(2, 3),(3, 1)$。

放置棋子 $3$ 後，它能走到的位置為 $(1, 1),(1, 3),(2, 2)$。

放置棋子 $4$ 後，它能走到的位置為 $(2, 2),(3, 1),(3, 3)$。

放置棋子 $5$ 後，它能走到的位置為 $(2, 3),(3, 2)$。


**【資料範圍】**

| 測試點編號 | $n \times m \le$ | $q \le$ | 特殊性質 |
|:-:|:-:|:-:|:-:|
| $1 \sim 2$ | $100$ | $50$ | 無 |
| $3 \sim 6$ | $5000$ | $2000$ | 無 |
| $7 \sim 8$ | $2 \times {10}^5$ | ${10}^5$ | 不存在“直行道路”與“互通道路” |
| $9 \sim 11$ | $2 \times {10}^5$ | ${10}^5$ | 不存在“互通道路” |
| $12 \sim 14$ | $2 \times {10}^5$ | ${10}^5$ | 不存在“直行道路” |
| $15 \sim 16$ | $2 \times {10}^5$ | ${10}^5$ | $\mathit{lv}_i = i$ |
| $17 \sim 18$ | $2 \times {10}^5$ | ${10}^5$ | $\mathit{lv}_i = q - i + 1$ |
| $19 \sim 21$ | $2 \times {10}^5$ | $2000$ | $n, m \le 1000$ |
| $22 \sim 25$ | $2 \times {10}^5$ | ${10}^5$ | 無 |

對於 $100 \%$ 的資料，$1 \le T \le 5$，$2 \le n, m \le {10}^5$，$4 \le n \times m \le 2 \times {10}^5$，$1 \le q \le \min \{ {10}^5, n \times m \}$，$1 \le \mathit{lv}_i \le q$，$1 \le x_i \le n$，$1 \le y_i \le m$，$\mathit{col}_i \in \{ 0, 1 \}$。

注：由於本題輸入輸出規模較大，建議使用較為快速的輸入輸出方式。
:::
