## Description · 題目說明

:::zh
動物園裡飼養了很多動物，飼養員小 A 會根據飼養動物的情況，按照《飼養指南》購買不同種類的飼料，並將購買清單發給採購員小 B。 

具體而言，動物世界裡存在 $2^k$ 種不同的動物，它們被編號為 $0 \sim 2^k - 1$。動物園裡飼養了其中的 $n$ 種，其中第 $i$ 種動物的編號為 $a_i$。

《飼養指南》中共有 $m$ 條要求，第 $j$ 條要求形如“如果動物園中飼養著某種動物，滿足其編號的二進位制表示的第 $p_j$ 位為 $1$，則必須購買第 $q_j$ 種飼料”。其中飼料共有 $c$ 種，它們從 $1 \sim c$ 編號。本題中我們將動物編號的二進位制表示視為一個 $k$ 位 01 串，第 $0$ 位是最低位，第 $k - 1$ 位是最高位。 

根據《飼養指南》，小 A 將會制定飼料清單交給小 B，由小 B 購買飼料。清單形如一個 $c$ 位 $01$ 串，第 $i$ 位為 $1$ 時，表示需要購買第 $i$ 種飼料；第 $i$ 位為 $0$ 時，表示不需要購買第 $i$ 種飼料。 實際上根據購買到的飼料，動物園可能可以飼養更多的動物。更具體地，如果將當前未被飼養的編號為 $x$ 的動物加入動物園飼養後，飼料清單沒有變化，那麼我們認為動物園當前還能飼養編號為 $x$ 的動物。

現在小 B 想請你幫忙算算，動物園目前還能飼養多少種動物。
:::

## Input · 輸入格式

:::zh
第一行包含四個以空格分隔的整數 $n, m, c, k$。  

分別表示動物園中動物數量、《飼養指南》要求數、飼料種數與動物編號的二進位制表示位數。   

第二行 $n$ 個以空格分隔的整數，其中第 $i$ 個整數表示 $a_i$。  

接下來 $m$ 行，每行兩個整數 $p_i, q_i$ 表示一條要求。  

資料保證所有 $a_i$ 互不相同，所有的 $q_i$ 互不相同。
:::

## Output · 輸出格式

僅一行一個整數表示答案。

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 #1 解釋】**

動物園裡飼養了編號為 $1, 4, 6$ 的三種動物，《飼養指南》上的三條要求為：

1. 若飼養的某種動物的編號的第 $0$ 個二進位制位為 $1$，則需購買第 $3$ 種飼料。
2. 若飼養的某種動物的編號的第 $2$ 個二進位制位為 $1$，則需購買第 $4$ 種飼料。
3. 若飼養的某種動物的編號的第 $2$ 個二進位制位為 $1$，則需購買第 $5$ 種飼料。 

飼料購買情況為：

1. 編號為 $1$ 的動物的第 $0$ 個二進位制位為 $1$，因此需要購買第 $3$ 種飼料；
2. 編號為 $4, 6$ 的動物的第 $2$ 個二進位制位為 $1$，因此需要購買第 $4, 5$ 種飼料。 

由於在當前動物園中加入一種編號為 $0, 2, 3, 5, 7, 8, \ldots , 15$ 之一的動物，購物清單都不會改變，因此答案為 $13$。

**【資料範圍】**

對於 $20 \%$ 的資料，$k \le n \le 5$，$m \le 10$，$c \le 10$，所有的 $p_i$ 互不相同。  

對於 $40 \%$ 的資料，$n \le 15$，$k \le 20$，$m \le 20$，$c \le 20$。  

對於 $60 \%$ 的資料，$n \le 30$，$k \le 30$，$m \le 1000$。  

對於 $100 \%$ 的資料，$0 \le n, m \le 10^6$，$0 \le k \le 64$，$1 \le c \le 10^8$。
:::
