## Description · 題目說明

:::zh
小簡單正在學習離散數學，今天的內容是圖論基礎，在課上他做了如下兩條筆記：
1. 一個大小為 $n$ 的樹由 $n$ 個結點與 $n - 1$ 條無向邊構成，且滿足任意兩個結點間**有且僅有**一條簡單路徑。在樹中刪去一個結點及與它關聯的邊，樹將分裂為若干個子樹；而在樹中刪去一條邊（保留關聯結點，下同），樹將分裂為**恰好**兩個子樹。
2. 對於一個大小為 $n$ 的樹與任意一個樹中結點 $c$，稱 $c$ 是該樹的**重心**當且僅當在樹中刪去 $c$ 及與它關聯的邊後，分裂出的所有子樹的大小均**不超過** $\lfloor \frac{n}{2} \rfloor$（其中 $\lfloor x \rfloor$ 是下取整函式）。對於包含至少一個結點的樹，它的重心只可能有 1 或 2 個。

課後老師給出了一個大小為 $n$ 的樹 $S$，樹中結點從 $1 \sim n$ 編號。小簡單的課後作業是求出 $S$ 單獨刪去每條邊後，分裂出的兩個子樹的重心編號和之和。即：

$$
\sum_{(u,v) \in E} \left( \sum_{1 \leq x \leq n \atop 且 x 號點是 S'_u 的重心} x + \sum_{1 \leq y \leq n \atop 且 y 號點是 S'_v 的重心} y \right)
$$

上式中，$E$ 表示樹 $S$ 的邊集，$(u,v)$ 表示一條連線 $u$ 號點和 $v$ 號點的邊。$S'_u$ 與 $S'_v$ 分別表示樹 $S$ 刪去邊 $(u,v)$ 後，$u$ 號點與 $v$ 號點所在的被分裂出的子樹。

小簡單覺得作業並不簡單，只好向你求助，請你教教他。
:::

## Input · 輸入格式

:::zh

第一行一個整數 $T$ 表示資料組數。

接下來依次給出每組輸入資料，對於每組資料：

第一行一個整數 $n$ 表示樹 $S$ 的大小。

接下來 $n − 1$ 行，每行兩個以空格分隔的整數 $u_i$，$v_i$，表示樹中的一條邊 $(u_i,v_i)$。

## Notes and Constraints · 說明與數據範圍

:::zh
【樣例 1 解釋】

對於第一組資料：

刪去邊 $(1,2)$，1 號點所在子樹重心編號為 $\{1\}$，2 號點所在子樹重心編號為 $\{2,3\}$。

刪去邊 $(2,3)$，2 號點所在子樹重心編號為 $\{2\}$，3 號點所在子樹重心編號為 $\{3,5\}$。

刪去邊 $(2,4)$，2 號點所在子樹重心編號為 $\{2,3\}$，4 號點所在子樹重心編號為 $\{4\}$。

刪去邊 $(3,5)$，3 號點所在子樹重心編號為 $\{2\}$，5 號點所在子樹重心編號為 $\{5\}$。

因此答案為 $1 + 2 + 3 + 2 + 3 + 5 + 2 + 3 + 4 + 2 + 5 = 32$。

【資料範圍】

| 測試點編號 | $n =$ | 特殊性質 |
| :----------- | :----------- | :----------- |
| $1 \sim 2$ | $7$ | 無 |
| $3 \sim 5$ | $199$ | 無 |
| $6 \sim 8$ | $1999$ | 無 |
| $9 \sim 11$ | $49991$ | A |
| $12 \sim 15$ | $262143$ | B |
| $16$ | $99995$ | 無 |
| $17 \sim 18$ | $199995$ | 無 |
| $19 \sim 20$ | $299995$ | 無 |


表中特殊性質一欄，兩個變數的含義為存在一個 $1 \sim n$ 的排列  $p_i (1 \leq i \leq n)$，使得：
- A：樹的形態是一條鏈。即 $\forall 1 \leq i \lt n$，存在一條邊 $(p_i, p_{i + 1})$。
- B：樹的形態是一個完美二叉樹。即 $\forall 1 \leq i \leq \frac{n-1}{2}$ ，存在兩條邊 $(p_i, p_{2i})$ 與 $(p_i, p_{2i+1})$。

對於所有測試點：$1 \leq T \leq 5 , 1 \leq u_i,v_i \leq n$。保證給出的圖是一個樹。
:::
