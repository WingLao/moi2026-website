## Description · 題目說明

:::zh
小 R 喜歡玩小木棍。小 R 有 $n$ 根小木棍，第 $i$ ($1 \leq i \leq n$) 根小木棍的長度為 $a_i$。

小 X 希望小 R 從這 $n$ 根小木棍中選出若干根小木棍，將它們按任意順序首尾相連拼成一個多邊形。小 R 並不知道小木棍能拼成多邊形的條件，於是小 X 直接將條件告訴了他：對於長度分別為 $l_1, l_2, \dots, l_m$ 的 $m$ 根小木棍，這 $m$ 根小木棍能拼成一個多邊形當且僅當 $m \geq 3$ 且所有小木棍的長度之和**大於**所有小木棍的長度最大值的兩倍，即 $\sum_{i=1}^{m} l_i > 2 \times \max_{i=1}^{m} l_i$。

由於小 R 知道了小木棍能拼成多邊形的條件，小 X 提出了一個更難的問題：有多少種選擇小木棍的方案，使得選出的小木棍能夠拼成一個多邊形？你需要幫助小 R 求出選出的小木棍能夠拼成一個多邊形的方案數。兩種方案不同當且僅當選擇的小木棍的**下標集合不同**，即存在 $1 \leq i \leq n$，使得其中一種方案選擇了第 $i$ 根小木棍，但另一種方案未選擇。由於答案可能較大，你只需要求出答案對 $998,244,353$ 取模後的結果。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含一個正整數 $n$，表示小 R 的小木棍的數量。

輸入的第二行包含 $n$ 個正整數 $a_1, a_2, \dots, a_n$，表示小 R 的小木棍的長度。
:::

## Output · 輸出格式

:::zh
輸出一行一個非負整數，表示小 R 選出的小木棍能夠拼成一個多邊形的方案數對 $998,244,353$ 取模後的結果。
:::
