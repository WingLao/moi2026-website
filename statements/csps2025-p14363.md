## Description · 題目說明

:::en
You are given $n$ string pairs $(s_{i,1}, s_{i,2})$ with $|s_{i,1}| = |s_{i,2}|$.

A **replacement** of a string $s$: write $s = x + y + z$ ($x, z$ may be empty, $+$ is concatenation) where $y = s_{i,1}$ for some $i$, and replace it to get $s' = x + s_{i,2} + z$.

There are $q$ queries; query $j$ gives two **different** strings $t_{j,1}, t_{j,2}$. How many replacements of $t_{j,1}$ produce $t_{j,2}$? Two replacements differ if the position of $y$ differs or the pair index $i$ differs.
:::

:::zh
小 W 是一名喜歡語言學的演算法競賽選手。在語言學中，諧音替換是指將原有的字詞替換為讀音相同或相近的字詞。小 W 發現，諧音替換的過程可以用字串來進行描述。具體地，小 W 將諧音替換定義為以下字串問題：

給定 $n$ 個字串二元組，第 $i$ ($1 \leq i \leq n$) 個字串二元組為 $(s_{i,1}, s_{i,2})$，滿足 $|s_{i,1}| = |s_{i,2}|$，其中 $|s|$ 表示字串 $s$ 的長度。

對於字串 $s$，定義 $s$ 的**替換**如下：

- 對於 $s$ 的某個子串 $y$，若存在 $1 \leq i \leq n$ 滿足 $y = s_{i,1}$，則將 $y$ 替換為 $y' = s_{i,2}$。具體地，設 $s = x + y + z$，其中 $x$ 和 $z$ 可以為空，“+” 表示字串拼接，則 $s$ 的替換將得到字串 $s' = x + y' + z$。

小 W 提出了 $q$ 個問題，第 $j$ ($1 \leq j \leq q$) 個問題會給定兩個**不同**的字串 $t_{j,1}, t_{j,2}$，她想知道有多少種字串 $t_{j,1}$ 的替換能夠得到字串 $t_{j,2}$。兩種 $s$ 的替換不同當且僅當**子串 $y$ 的位置不同或用於替換的二元組 $(s_{i,1}, s_{i,2})$ 不同**，即 $x, z$ 不同或 $i$ 不同。你需要回答小 W 提出的所有問題。
:::

:::en

Next $n$ lines: two strings $s_{i,1}, s_{i,2}$.

Next $q$ lines: two strings $t_{j,1}, t_{j,2}$.
:::

:::zh
輸入的第一行包含兩個正整數 $n, q$，分別表示字串二元組的數量和小 W 提出的問題的數量。

輸入的第 $i+1$ ($1 \leq i \leq n$) 行包含兩個字串 $s_{i,1}, s_{i,2}$，表示第 $i$ 個字串二元組。

輸入的第 $j+n+1$ ($1 \leq j \leq q$) 行包含兩個字串 $t_{j,1}, t_{j,2}$，表示小 W 提出的第 $j$ 個問題。
:::

## Output · 輸出格式

:::en

:::

:::zh

### 【樣例 1 解釋】

對於小 W 的第一個詢問，共有 $2$ 種 $t_{1,1}$ 的替換能夠得到 $t_{1,2}$:

1. 令 $x, z$ 均為空串，$y = \texttt{xabcx}$, $i = 1$，則 $y' = \texttt{xadex}$，替換後得到 $\texttt{xadex}$；
2. 令 $x = \texttt{xa}$, $y = \texttt{bc}$, $z = \texttt{x}$, $i = 3$，則 $y' = \texttt{de}$，替換後得到 $\texttt{xadex}$。

### 【資料範圍】

- $1 \leq n, q \leq 2 \times 10^5$;
- $2 \leq L_1, L_2 \leq 5 \times 10^6$;
