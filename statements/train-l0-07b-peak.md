## 題目說明

一組數先上升，到達最高點後下降，像一座山。請輸出最高點（山頂）的位置（位置由 0 開始）。

## 輸入格式

| 行 | 內容 |
|---|---|
| 第 1 行 | 整數 n |
| 第 2 行 | n 個不同的整數，形狀一定是一座山 |

## 輸出格式

一個整數：山頂的位置。

## 樣例 1

輸入：

```text
6
12 35 52 68 47 27
```

輸出：

```text
3
```


**樣例 1 解釋**

| 位置 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 數 | 12 | 35 | 52 | **68** | 47 | 27 |
| 比左邊大？ | — | ✓ | ✓ | ✓ | ✗ | ✗ |
| 比右邊大？ | ✗ | ✗ | ✗ | ✓ | ✓ | — |

只有位置 3 比左右兩邊都大。

## 樣例 2

輸入：

```text
3
0 1 0
```

輸出：

```text
1
```


**樣例 2 解釋**

最短的山：0 → 1 → 0，山頂在位置 1。

## 數據範圍

| 測試點 | n |
|---|---|
| 1–5 | 3 ≤ n ≤ 100 |
| 6–10 | 3 ≤ n ≤ 1000 |

全部測試點：每個數在 0 到 10⁶ 之間；山頂不會在第 0 格或最後一格。
