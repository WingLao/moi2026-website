## Description · 題目說明

:::en
Given integers $n, m, k$ and positive integers $v_0, v_1, \ldots, v_m$.

For a sequence $a_1, \ldots, a_n$ of non-negative integers not exceeding $m$, its weight is $v_{a_1} \times v_{a_2} \times \cdots \times v_{a_n}$. The sequence is valid if $S = 2^{a_1} + 2^{a_2} + \cdots + 2^{a_n}$ has at most $k$ ones in binary.

Find the sum of weights of all valid sequences modulo $998244353$.
:::

:::zh
給定整數 $n, m, k$，和一個長度為 $m + 1$ 的正整數陣列 $v_0, v_1, \ldots, v_m$。

對於一個長度為 $n$，下標從 $1$ 開始且每個元素均不超過 $m$ 的非負整數序列 $\{a_i\}$，我們定義它的權值為 $v_{a_1} \times v_{a_2} \times \cdots \times v_{a_n}$。

當這樣的序列 $\{a_i\}$ 滿足整數 $S = 2^{a_1} + 2^{a_2} + \cdots + 2^{a_n}$ 的二進位制表示中 $1$ 的個數不超過 $k$ 時，我們認為 $\{a_i\}$ 是一個合法序列。

計算所有合法序列 $\{a_i\}$ 的權值和對 $998244353$ 取模的結果。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

由於 $k = 1$，而且由 $n \leq S \leq n \times 2^m$ 知道 $5 \leq S \leq 10$，合法的 $S$ 只有一種可能：$S = 8$，這要求 $a$ 中必須有 $2$ 個 $0$ 和 $3$ 個 $1$，於是有 $\binom{5}{2} = 10$ 種可能的序列，每種序列的貢獻都是 $v_0^2 v_1^3 = 4$，權值和為 $10 \times 4 = 40$。

**【資料範圍】**

對所有測試點保證 $1 \leq k \leq n \leq 30$，$0 \leq m \leq 100$，$1 \leq v_i < 998244353$。
