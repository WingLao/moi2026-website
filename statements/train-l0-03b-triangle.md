## 題目說明

給出三條線段的長度 a, b, c。判斷它們能組成哪一種三角形，按下表輸出代號：

| 代號 | 情況 |
|---|---|
| 0 | 不能組成三角形（某兩邊之和 ≤ 第三邊） |
| 1 | 等邊三角形 |
| 2 | 等腰三角形（恰好兩邊相等） |
| 3 | 直角三角形 |
| 4 | 其他三角形 |

三條邊的次序不一定由小到大。

## 輸入格式

一行三個整數 a, b, c。

## 輸出格式

一個整數：代號。

## 樣例 1

輸入：

```text
3 4 5
```

輸出：

```text
3
```


**樣例 1 解釋**

（圖解見培訓路線網站的單元頁）
3 + 4 > 5，可以組成三角形；三邊都不相等；3² + 4² = 9 + 16 = 25 = 5²，是直角三角形。

## 樣例 2

輸入：

```text
2 2 5
```

輸出：

```text
0
```


**樣例 2 解釋**

2 + 2 = 4 ≤ 5，不能組成三角形。先判斷「能不能組成」，才判斷種類。

> 注意：邊長可達 2 × 10⁹，超過 `int`；兩邊之和、邊長的平方更大。

## 數據範圍

| 測試點 | a, b, c |
|---|---|
| 1–4 | 1 ≤ a, b, c ≤ 1000 |
| 5–10 | 1 ≤ a, b, c ≤ 2 × 10⁹ |
