## Description · 題目說明

:::zh
小 N 和小 O 會在 2022 年 11 月參加一場盛大的程式設計大賽 NOIP！小 P 會作為裁判主持競賽。小 N 和小 O 各自率領了一支 $n$ 個人的隊伍，選手在每支隊伍內都是從 $1$ 到 $n$ 編號。每一個選手都有相應的程式設計水平。具體的，小 N 率領的隊伍中，編號為 $i$（$1 \leq i \leq n$）的選手的程式設計水平為 $a _ i$；小 O 率領的隊伍中，編號為 $i$（$1 \leq i \leq n$）的選手的程式設計水平為 $b _ i$。特別地，$\{a _ i\}$ 和 $\{b _ i\}$ 還分別構成了從 $1$ 到 $n$ 的排列。

每場比賽前，考慮到路途距離，選手連續參加比賽等因素，小 P 會選擇兩個引數 $l, r$（$1 \leq l \leq r \leq n$），表示這一場比賽會邀請兩隊中編號屬於 $[l, r]$ 的所有選手來到現場準備比賽。在比賽現場，小 N 和小 O 會以擲骰子的方式挑選出引數 $p, q$（$l \leq p \leq q \leq r$），只有編號屬於 $[p, q]$ 的選手才能參賽。為了給觀眾以最精彩的比賽，兩隊都會派出編號在 $[p, q]$ 內的、程式設計水平值最大的選手參加比賽。假定小 N 派出的選手水平為 $m _ a$，小 O 派出的選手水平為 $m _ b$，則比賽的精彩程度為 $m _ a \times m _ b$。

NOIP 總共有 $Q$ 場比賽，每場比賽的引數 $l, r$ 都已經確定，但是 $p, q$ 還沒有抽取。小 P 想知道，對於每一場比賽，在其所有可能的 $p, q$（$l \leq p \leq q \leq r$）引數下的比賽的精彩程度之和。由於答案可能非常之大，你只需要對每一場答案輸出結果對 $2 ^ {64}$ 取模的結果即可。
:::

## Input · 輸入格式

:::zh
第一行包含兩個正整數 $T, n$，分別表示測試點編號和參賽人數。如果資料為樣例則保證 $T = 0$。

第二行包含 $n$ 個正整數，第 $i$ 個正整數為 $a _ i$，表示小 N 隊伍中編號為 $i$ 的選手的程式設計水平。

第三行包含 $n$ 個正整數，第 $i$ 個正整數為 $b _ i$，表示小 O 隊伍中編號為 $i$ 的選手的程式設計水平。

第四行包含一個正整數 $Q$，表示比賽場數。

接下來的 $Q$ 行，第 $i$ 行包含兩個正整數 $l _ i, r _ i$，表示第 $i$ 場比賽的引數 $l, r$。
:::

## Output · 輸出格式

:::zh
輸出 $Q$ 行，第 $i$ 行包含一個非負整數，表示第 $i$ 場比賽中所有可能的比賽的精彩程度之和對 $2 ^ {64}$ 取模的結果。
:::
