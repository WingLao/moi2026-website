## Description · 題目說明

:::en
Little X gives Little R a string $s$ of lowercase letters and digits that contains **at least one digit from $1$ to $9$**. Little R uses any number of the digits in $s$, in any order, to form a positive integer. **Each digit character can be used at most once** (equal digits may both be used). E.g. for $\tt 1a01b$ he can choose $1, 0, 1$ and form $101$ or $110$, but not $111$, because $s$ has only two $1$s.

Find the largest positive integer he can form.
:::

:::zh
小 R 正在學習字串處理。小 X 給了小 R 一個字串 $s$，其中 $s$ 僅包含小寫英文字母及數字，且**包含至少一個 $1 \sim 9$ 中的數字**。小 X 希望小 R 使用 $s$ 中的任意多個數字，按任意順序拼成一個正整數。**注意：小 R 可以選擇 $s$ 中相同的數字，但每個數字只能使用一次**。例如，若 $s$ 為 $\tt 1a01b$，則小 R 可以同時選擇第 $1,3,4$ 個字元，分別為 $1,0,1$，拼成正整數 $101$ 或 $110$；但小 R 不能拼成正整數 $111$，因為 $s$ 僅包含兩個數字 $1$。小 R 想知道，在他所有能拼成的正整數中，最大的是多少。你需要幫助小 R 求出他能拼成的正整數的最大值。
:::
