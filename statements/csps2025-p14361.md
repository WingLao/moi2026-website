## Description · 題目說明

:::zh
小 L 是學校演算法協會的成員。在今年的學校社團招新中，小 L 一共招收了 $n$ 個新成員，其中 $n$ 為**偶數**。現在小 L 希望將他們分到協會不同的部門。

演算法協會共設有三個部門，其中第 $i$ ($1 \leq i \leq n$) 個新成員對第 $j$ ($1 \leq j \leq 3$) 個部門的滿意度為 $a_{i,j}$。定義一個分配方案的滿意度為所有新成員對分配到的部門的滿意度之和，也就是說，若將第 $i$ ($1 \leq i \leq n$) 個新成員分配到了第 $d_i \in \{1,2,3\}$ 個部門，則該分配方案的滿意度為 $\sum_{i=1}^{n} a_{i,d_i}$。

小 L 不希望某一個部門的新成員數量過多。具體地，他要求在分配方案中，不存在一個部門被分配多於 $\frac{n}{2}$ 個新成員。你需要幫助小 L 求出，滿足他要求的分配方案的滿意度的最大值。
:::

## Input · 輸入格式

:::zh
本題包含多組測試資料。

輸入的第一行包含一個正整數 $t$，表示測試資料組數。

接下來依次輸入每組測試資料，對於每組測試資料：

- 第一行包含一個正整數 $n$，表示新成員的數量。
- 第 $i+1$ ($1 \leq i \leq n$) 行包含三個非負整數 $a_{i,1}, a_{i,2}, a_{i,3}$，分別表示第 $i$ 個新成員對第 $1,2,3$ 個部門的滿意度。
:::

## Output · 輸出格式

:::zh
對於每組測試資料，輸出一行一個非負整數，表示滿足小 L 要求的分配方案的滿意度的最大值。
:::

### 【樣例 1 解釋】

該樣例共包含三組測試資料。

對於第一組測試資料，可以將四個新成員分別分配到第 $1,3,1,2$ 個部門，則三個部門的新成員數量分別為 $2,1,1$，均不超過 $\frac{4}{2} = 2$，滿意度為 $4 + 4 + 5 + 5 = 18$。

對於第二組測試資料，可以將四個新成員分別分配到第 $1,1,2,2$ 個部門，則三個部門的新成員數量分別為 $2,2,0$，均不超過 $\frac{4}{2} = 2$，滿意度為 $0 + 0 + 2 + 2 = 4$。

對於第三組測試資料，可以將兩個新成員分別分配到第 $2,1$ 個部門，則三個部門的新成員數量分別為 $1,1,0$，均不超過 $\frac{2}{2} = 1$，滿意度為 $9 + 4 = 13$。
