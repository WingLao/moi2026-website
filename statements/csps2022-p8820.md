## Description · 題目說明

:::zh
小 C 正在設計計算機網路中的路由系統。

測試用的網路總共有 $n$ 臺主機，依次編號為 $1 \sim n$。這 $n$ 臺主機之間由 $n - 1$ 根網線連線，第 $i$ 條網線連線兩個主機 $a_i$ 和 $b_i$。保證任意兩臺主機可以透過有限根網線直接或者間接地相連。受制於資訊傳送的功率，主機 $a$ 能夠直接將資訊傳輸給主機 $b$ 當且僅當兩個主機在可以透過不超過 $k$ 根網線直接或者間接的相連。

在計算機網路中，資料的傳輸往往需要透過若干次轉發。假定小 C 需要將資料從主機 $a$ 傳輸到主機 $b$（$a \neq b$），則其會選擇出若干臺用於傳輸的主機 $c_1 = a, c_2, \ldots, c_{m - 1}, c_m = b$，並按照如下規則轉發：對於所有的 $1 \le i < m$，主機 $c_i$ 將資訊直接傳送給 $c_{i + 1}$。

每臺主機處理資訊都需要一定的時間，第 $i$ 臺主機處理資訊需要 $v_i$ 單位的時間。資料在網路中的傳輸非常迅速，因此傳輸的時間可以忽略不計。據此，上述傳輸過程花費的時間為 $\sum_{i = 1}^{m} v_{c_i}$。

現在總共有 $q$ 次資料傳送請求，第 $i$ 次請求會從主機 $s_i$ 傳送資料到主機 $t_i$。小 C 想要知道，對於每一次請求至少需要花費多少單位時間才能完成傳輸。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含三個正整數 $n, Q, k$，分別表示網路主機個數，請求個數，傳輸引數。資料保證 $1 \le n \le 2 \times {10}^5$，$1 \le Q \le 2 \times {10}^5$，$1 \le k \le 3$。

輸入的第二行包含 $n$ 個正整數，第 $i$ 個正整數表示 $v_i$，保證 $1 \le v_i \le {10}^9$。

接下來 $n - 1$ 行，第 $i$ 行包含兩個正整數 $a_i, b_i$，表示一條連線主機 $a_i, b_i$ 的網線。保證 $1 \le a_i, b_i \le n$。

接下來 $Q$ 行，第 $i$ 行包含兩個正整數 $s_i, t_i$，表示一次從主機 $s_i$ 傳送資料到主機 $t_i$ 的請求。保證 $1 \le s_i, t_i \le n$，$s_i \ne t_i$。
:::

## Output · 輸出格式

:::zh
$Q$ 行，每行一個正整數，表示第 $i$ 次請求在傳輸的時候至少需要花費多少單位的時間。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 \#1】**

對於第一組請求，由於主機 $4, 7$ 之間需要至少 $4$ 根網線才能連線，因此資料無法在兩臺主機之間直接傳輸，其至少需要一次轉發；我們讓其在主機 $1$ 進行一次轉發，不難發現主機 $1$ 和主機 $4, 7$ 之間都只需要兩根網線即可連線，且主機 $1$ 的資料處理時間僅為 $1$，為所有主機中最小，因此最少傳輸的時間為 $4 + 1 + 7 = 12$。

對於第三組請求，由於主機 $1, 2$ 之間只需要 $1$ 根網線就能連線，因此資料直接傳輸就是最優解，最少傳輸的時間為 $1 + 2 = 3$。
