## Description · 題目說明

:::en
Given a non-decreasing sequence of positive integers $1 \le a_1 \le a_2 \le \cdots \le a_n$. One operation: choose $1 < i < n$ and replace $a_i$ by $a_{i - 1} + a_{i + 1} - a_i$. After any number of operations, what is the minimum variance? Output the minimum multiplied by $n^2$.

Variance: $D = \frac{1}{n} \sum_{i = 1}^{n} {(a_i - \bar a)}^2$ with $\bar a = \frac{1}{n} \sum_{i = 1}^{n} a_i$.
:::

:::zh
給定長度為 $n$ 的非嚴格遞增正整數數列 $1 \le a_1 \le a_2 \le \cdots \le a_n$。每次可以進行的操作是：任意選擇一個正整數 $1 < i < n$，將 $a_i$ 變為 $a_{i - 1} + a_{i + 1} - a_i$。求在若干次操作之後，該數列的方差最小值是多少。請輸出最小值乘以 $n^2$ 的結果。

其中方差的定義為：數列中每個數與平均值的差的平方的平均值。更形式化地說，方差的定義為 $D = \frac{1}{n} \sum_{i = 1}^{n} {(a_i - \bar a)}^2$，其中 $\bar a = \frac{1}{n} \sum_{i = 1}^{n} a_i$。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

對於 $(a_1, a_2, a_3, a_4) = (1, 2, 4, 6)$，第一次操作得到的數列有 $(1, 3, 4, 6)$，第二次操作得到的新的數列有 $(1, 3, 5, 6)$。之後無法得到新的數列。

對於 $(a_1, a_2, a_3, a_4) = (1, 2, 4, 6)$，平均值為 $\frac{13}{4}$，方差為 $\frac{1}{4}({(1 - \frac{13}{4})}^2 + {(2 - \frac{13}{4})}^2 + {(4 - \frac{13}{4})}^2 + {(6 - \frac{13}{4})}^2) = \frac{59}{16}$。

對於 $(a_1, a_2, a_3, a_4) = (1, 3, 4, 6)$，平均值為 $\frac{7}{2}$，方差為 $\frac{1}{4} ({(1 - \frac{7}{2})}^2 + {(3 - \frac{7}{2})}^2 + {(4 - \frac{7}{2})}^2 + {(6 - \frac{7}{2})}^2) = \frac{13}{4}$。

對於 $(a_1, a_2, a_3, a_4) = (1, 3, 5, 6)$，平均值為 $\frac{15}{4}$，方差為 $\frac{1}{4} ({(1 - \frac{15}{4})}^2 + {(3 - \frac{15}{4})}^2 + {(5 - \frac{15}{4})}^2 + {(6 - \frac{15}{4})}^2) = \frac{59}{16}$。
