## Description · 題目說明

:::zh
小 F 有 $n$ 個變數 $x_1, x_2, \ldots , x_n$。每個變數可以取 $1$ 至 $v$ 的整數取值。

小 F 在這 $n$ 個變數之間新增了 $n - 1$ 條二元限制，其中第 $i$（$1 \leq i \leq n - 1$）條限制為：若 $x_i = a_i$，則要求 $x_{i+1} = b_i$，**且 $a_i$ 與 $b_i$ 為 $1$ 到 $v$ 之間的整數**；當 $x_i \neq a_i$ 時，第 $i$ 條限制對 $x_{i+1}$ 的值不做任何約束。除此之外，小 F 還新增了 $m$ 條一元限制，其中第 $j$（$1 \leq j \leq m$）條限制為：$x_{c_j} = d_j$。

小 F 記住了所有 $c_j$ 和 $d_j$ 的值，但把所有 $a_i$ 和 $b_i$ 的值都忘了。同時小 F 知道：存在給每一個變數賦值的方案同時滿足所有這些限制。

現在小 F 想知道，有多少種 $a_i, b_i$（$1 \leq i \leq n - 1$）取值的組合，使得能夠確保至少存在一種給每個變數 $x_i$ 賦值的方案可以同時滿足所有限制。由於方案數可能很大，小 F 只需要你輸出方案數對 $10^9 + 7$ 取模的結果。
:::

## Input · 輸入格式

:::zh
**本題包含多組測試資料**。

輸入的第一行包含一個整數 $T$，表示測試資料的組數。

接下來包含 $T$ 組資料，每組資料的格式如下：

第一行包含三個整數 $n, m, v$，分別表示變數個數、一元限制個數和變數的取值上限。

接下來 $m$ 行，第 $j$ 行包含兩個整數 $c_j, d_j$，描述一個一元限制。
:::

## Output · 輸出格式

:::zh
對於每組測試資料輸出一行，包含一個整數，表示方案數對 $10^9 + 7$ 取模的結果。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

- 對於第一組測試資料，所有可能的 $(a_1, b_1)$ 取值的組合 $(1, 1), (1, 2), (2, 1), (2, 2)$ 都滿足限制。例如，$(a_1, b_1) = (1, 1)$ 時，$(x_1, x_2) = (1, 1)$ 滿足所有限制，而 $(a_1, b_1) = (2, 2)$ 時，$(x_1, x_2) = (1, 1)$ 與 $(x_1, x_2) = (1, 2)$ 均滿足所有限制。
- 對於第二組測試資料，只有 $(x_1, x_2) = (1, 2)$ 一種可能的變數賦值，因此只有 $(a_1, b_1) = (1, 1)$ 不滿足限制，其餘三種賦值均滿足限制。
- 對於第三組測試資料，不存在一種變數賦值同時滿足 $x_1 = 1$ 和 $x_1 = 2$，因此也不存在滿足限制的 $(a_1, b_1)$。
