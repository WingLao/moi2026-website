## Description · 題目說明

:::en
A tree has $n$ nodes numbered $1 \sim n$. Initially every node holds one of the digits $1 \sim n$, each digit on **exactly** one node.

Perform **exactly** $n - 1$ deletions: each time choose an edge **not yet deleted**, **swap** the numbers on its two ends, then delete the edge.

Afterwards, list the nodes holding numbers $1, 2, \ldots, n$ in order; this gives a permutation $P$ of node numbers. Find the **lexicographically smallest** $P$ achievable (see the figures in the Chinese statement for an example).
:::

:::zh
給定一個大小為 $n$ 的樹，它共有 $n$ 個結點與 $n - 1$ 條邊，結點從 $1 \sim n$ 編號。初始時每個結點上都有一個 $1 \sim n$ 的數字，且每個 $1 \sim n$ 的數字都只在**恰好**一個結點上出現。

接下來你需要進行**恰好** $n - 1$ 次刪邊操作，每次操作你需要選一條**未被刪去**的邊，此時這條邊所連線的兩個結點上的數字將會**交換**，然後這條邊將被刪去。

$n - 1$ 次操作過後，所有的邊都將被刪去。此時，按數字從小到大的順序，將數字 $1 \sim n$ 所在的結點編號依次排列，就得到一個結點編號的排列 $P_i$。現在請你求出，在最優操作方案下能得到的**字典序最小**的 $P_i$。

![](https://cdn.luogu.com.cn/upload/image_hosting/flbxosct.png)

如上圖，藍圈中的數字 $1 \sim 5$ 一開始分別在結點②、①、③、⑤、④。按照 (1)(4)(3)(2) 的順序刪去所有邊，樹變為下圖。按數字順序得到的結點編號排列為①③④②⑤，該排列是所有可能的結果中字典序最小的。

![](https://cdn.luogu.com.cn/upload/image_hosting/tu338qm9.png)
:::

## Input · 輸入格式

:::en
**Multiple test cases.** Line 1: a positive integer $T$.

Each case: a line with $n$; a line with $n$ integers, the $i$-th being the node that initially holds number $i$; then $n - 1$ lines with $x, y$, an edge.
:::

:::zh
**本題輸入包含多組測試資料。**

第一行一個正整數 $T$，表示資料組數。

對於每組測試資料：

第一行一個整數 $n$，表示樹的大小。

第二行 $n$ 個整數，第 $i (1 \leq i \leq n)$ 個整數表示數字 $i$ 初始時所在的結點編號。

接下來 $n - 1$ 行每行兩個整數 $x$, $y$，表示一條連線 $x$ 號結點與 $y$ 號結點的邊。
:::

## Output · 輸出格式

:::en
For each case, one line with $n$ integers separated by spaces: the smallest $P$.
:::

:::zh
對於每組測試資料，輸出一行共 $n$ 個用空格隔開的整數，表示最優操作方案下所能得到的字典序最小的 $P_i$。
:::
