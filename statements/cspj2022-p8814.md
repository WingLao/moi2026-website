## Description · 題目說明

:::en
Given a positive integer $k$, there are $k$ queries. Each gives three positive integers $n_i, e_i, d_i$; find two positive integers $p_i, q_i$ with $n_i = p_i \times q_i$ and $e_i \times d_i = (p_i - 1)(q_i - 1) + 1$.
:::

:::zh
給定一個正整數 $k$，有 $k$ 次詢問，每次給定三個正整數 $n_i, e_i, d_i$，求兩個正整數 $p_i, q_i$，使 $n_i = p_i \times q_i$、$e_i \times d_i = (p_i - 1)(q_i - 1) + 1$。
:::

## Input · 輸入格式

:::en
Line 1: a positive integer $k$.

Next $k$ lines: line $i$ has three positive integers $n_i, d_i, e_i$.
:::

:::zh
第一行一個正整數 $k$，表示有 $k$ 次詢問。

接下來 $k$ 行，第 $i$ 行三個正整數 $n_i, d_i, e_i$。
:::

## Output · 輸出格式

:::en
$k$ lines, each with two positive integers $p_i, q_i$ with $p_i \leq q_i$. If there is no solution, output `NO`.
:::

:::zh
輸出 $k$ 行，每行兩個正整數 $p_i, q_i$ 表示答案。

為使輸出統一，你應當保證 $p_i \leq q_i$。

如果無解，請輸出 `NO`。
:::
