## Description · 題目說明

:::zh
小 Q 在與電腦玩一款名為“絕對防禦”的回合制卡牌遊戲。

小 Q 有一個大小為 $n$ 的牌堆，包含兩種牌：攻擊牌與防禦牌。遊戲開始時，小 Q 會從**牌堆頂**抽取 $k \ (1 \leq k \leq n)$ 張牌作為初始手牌，接下來他會與電腦進行若干輪對戰。

每輪對戰開始時，小 Q 從牌堆頂抽取 $2$ 張牌。特別地，若牌堆只剩餘 $1$ 張牌，則小 Q 只抽取 $1$ 張。一輪對戰分為兩個**回合**：

- 第一回合：小 Q 為攻擊方，電腦為防禦方；
- 第二回合：小 Q 為防禦方，電腦為攻擊方。

在每**回合**中，攻擊方**必須**從手牌中選擇一張**攻擊牌**進行攻擊，防禦方**必須**從手牌打出一張**防禦牌**進行防禦。無法按要求出牌者立即判負。

電腦的攻擊牌與防禦牌都是無限的，即電腦總能打出對應牌。為平衡電腦的實力，小 Q 可以使用一種特殊技能：當小 Q 為**防禦方**時，他可以從手牌打出一張**攻擊牌**進行防禦。該技能每 $3$ 輪**對戰**才能使用一次，即在某輪使用技能後，接下來的 $2$ 輪對戰中不能使用該技能。

在給定規則下，小 Q 的獲勝目標為在電腦猛烈攻擊中倖存，即在某輪對戰結束後，牌堆被抽空。特別地，若遊戲開始時牌堆已被抽空，則小 Q 直接達成獲勝目標。小 Q 想知道最小的初始抽牌數 $k$，使得他能達成勝利目標。

小 Q 覺得這個問題過於簡單，因此他增加了 $q$ 次修改操作。第 $i \ (1 \leq i \leq q)$ 次修改操作給定一個正整數 $x_i$，改變牌堆頂到牌堆底的第 $x_i$ 張牌的型別，即將攻擊牌變為防禦牌，將防禦牌變為攻擊牌。你需要對初始牌堆及每次修改後的牌堆，求出最小的小 Q 初始抽牌數 $k$，使得小 Q 能達成勝利目標。
:::

## Input · 輸入格式

:::zh
**本題包含多組測試資料**。

輸入的第一行包含兩個非負整數 $c,t$，分別表示測試點編號與測試資料組數。$c = 0$ 表示測試點為樣例。

接下來依次輸入每組測試資料，對於每組測試資料：

第一行包含兩個非負整數 $n, q$，分別表示牌堆大小與修改次數。

第二行包含一個長度為 $n$ 的字串 $s_1 s_2 \ldots s_n$，分別表示從牌堆頂到底的每張牌，

其中 $s_i = 0$ 表示第 $i$ 張牌為攻擊牌，$s_i = 1$ 表示第 $i$ 張牌為防禦牌。

第 $i + 2 \ (1 \leq i \leq q)$ 行包含一個正整數 $x_i$，表示第 $i$ 次修改的牌為從牌堆頂到牌堆底的第 $x_i$ 張牌。
:::

## Output · 輸出格式

:::zh
對於每組測試資料，設初始時的答案為 $k_0$，第 $i$ ($1 \leq i \leq q$) 次修改後的答案為 $k_i$，輸出一行 $q+1$ 個正整數 $k_0,k_1,\ldots,k_q$，表示初始時及每次修改後的最小抽牌數，使得小 Q 能達成獲勝目標。
:::

#### 【樣例 1 解釋】

該樣例共包含三組測試資料。

對於第一組測試資料：

- 初始時，牌堆為 $01010$。若初始抽牌數為 $1$，小 Q 的一種可能的出牌方式為：
  - 初始時手牌為 $\{0\}$;
  - 從堆頂抽取兩張牌，打出一張攻擊牌，一張防禦牌，手牌變為 $\{0\}$;
  - 從堆頂抽取兩張牌，打出一張攻擊牌，一張防禦牌，手牌變為 $\{0\}$，此時牌堆被抽空。

由於初始至少需要抽取一張牌，所以最小初始抽牌數為 $1$，故 $k_0=1$。
- 第一次修改後，牌堆變為 $01000$。若初始抽牌數為 $1$，小 Q 的一種可能的出牌方式為：
  - 初始時手牌為 $\{0\}$;
  - 從堆頂抽取兩張牌，打出一張攻擊牌，一張防禦牌，手牌變為 $\{0\}$;
  - 從堆頂抽取兩張牌，打出一張攻擊牌，使用特殊技能再次打出一張攻擊牌進行防禦，手牌變為 $\{0\}$，此時牌堆被抽空。
  
由於初始至少需要抽取一張牌，所以最小初始抽牌數為 1，故 $k_1=1$。

對於第二組測試資料：

若初始抽牌數為 $3$，小 Q 的一種可能的出牌方式為：
- 初始時手牌為 $\{0,0,0\}$;
- 從堆頂抽取兩張牌，打出一張攻擊牌，一張防禦牌，手牌變為 $\{0,0,0\}$;
- 從堆頂抽取兩張牌，打出一張攻擊牌，使用特殊技能再次打出一張攻擊牌進行防禦，手牌變為 $\{0,0,0\}$，此時牌堆被抽空。
可以證明，不存在比 $3$ 更小的初始抽牌數能夠抽空牌堆，故答案為 $3$。

對於第三組測試資料：

若初始抽牌數為 $2$，小 Q 的一種可能的出牌方式為：
- 初始時手牌為 $\{0,0\}$;
- 從堆頂抽取兩張牌，打出一張攻擊牌，使用特殊技能再次打出一張攻擊牌進行防禦，手牌變為 $\{0,1\}$;
- 從堆頂抽取兩張牌，打出一張攻擊牌，一張防禦牌，手牌變為 $\{0,1\}$;
- 從堆頂抽取兩張牌，打出一張攻擊牌，一張防禦牌，手牌變為 $\{0,0\}$，此時牌堆被抽空。
可以證明，不存在比 $2$ 更小的初始抽牌數能夠抽空牌堆，故答案為 $2$。

### 資料範圍

設 $N, Q$ 分別為單個測試點內所有測試資料的 $n, q$ 的和。對於所有測試資料，保證：

- $1 \leq t \leq 10^5$；
- $1 \leq n \leq 2 \times 10^5$，$N \leq 5 \times 10^5$；
- $0 \leq q \leq 2 \times 10^5$，$Q \leq 5 \times 10^5$；
- 對於所有 $1 \leq i \leq n$，均有 $s_i \in \{ 0, 1 \}$；
- 對於所有 $1 \leq i \leq q$，均有 $1 \leq k_i < n$。
