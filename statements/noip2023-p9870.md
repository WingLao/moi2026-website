## Description · 題目說明

:::en
A sequence $B = \{b_1, \ldots, b_n\}$ is an **extension** of $A = \{a_1, \ldots, a_m\}$ if there are **positive** integers $l_1, \ldots, l_m$ such that replacing each $a_i$ by $l_i$ copies of $a_i$ gives $B$. E.g. $\{1,3,3,3,2,2,2\}$ extends $\{1,3,3,2\}$, but $\{1,3,3,2\}$ does not extend $\{1,3,3,3,2\}$, and $\{1,2,3\}$ does not extend $\{1,3,2\}$.

Given sequences $X$ and $Y$, decide whether there are an extension $F$ of $X$ and an extension $G$ of $Y$, both of length $l_0 = 10^{100}$, such that $(f_i - g_i)(f_j - g_j) > 0$ for all $1 \le i, j \le l_0$ (i.e. $F$ is entirely above $G$ or entirely below).

There are also $q$ extra queries, each modifying some elements of $X$ and $Y$; answer the same question for each. **Queries are independent: each one modifies the original sequences.**
:::

:::zh
稱某個序列 $B = \{b_1,b_2,\cdots,b_n\}$ 是另一個序列 $A = \{a_1,a_2,\cdots,a_m\}$ 的**拓展**當且僅當存在**正整數**序列 $L = \{l_1,l_2,\cdots,l_m\}$，將 $a_i$ 替換為 $l_i$ 個 $a_i$ 後得到序列 $B$。例如，

- $\{1,3,3,3,2,2,2\}$ 是 $\{1,3,3,2\}$ 的拓展，取 $L = \{1,1,2,3\}$ 或 $\{1,2,1,3\}$；
- 而 $\{1,3,3,2\}$ 不是 $\{1,3,3,3,2\}$ 的拓展，$\{1,2,3\}$ 不是 $\{1,3,2\}$ 的拓展。

小 R 給了你兩個序列 $X$ 和 $Y$，他希望你找到 $X$ 的一個長度為 $l_0 = 10^{100}$ 的拓展 $F = \{f_i\}$ 以及 $Y$ 的一個長度為 $l_0$ 的拓展 $G = \{g_i\}$，使得任意 $1 \le i , j \le l_0$ 都有 $(f_i - g_i)(f_j - g_j) > 0$。由於序列太長，你只需要告訴小 R 是否存在這樣的兩個序列即可。

為了避免你扔硬幣矇混過關，小 R 還給了 $q$ 次額外詢問，每次額外詢問中小 R 會修改 $X$ 和 $Y$ 中若干元素的值。你需要對每次得到的新的 $X$ 和 $Y$ 都進行上述的判斷。

**詢問之間是獨立的，每次詢問中涉及的修改均在原始序列上完成。**
:::

## Input · 輸入格式

:::en
Line 1: four integers $c, n, m, q$ (test id, lengths of $X$ and $Y$, number of extra queries).

Line 2: $x_1, \ldots, x_n$. Line 3: $y_1, \ldots, y_m$.

Each query: a line with $k_x, k_y$; then $k_x$ lines $p_x, v_x$ (set $x_{p_x} = v_x$); then $k_y$ lines $p_y, v_y$ (set $y_{p_y} = v_y$).
:::

:::zh
輸入的第一行包含四個整數 $c, n, m, q$，分別表示測試點編號、序列 $X$ 的長度、序列 $Y$ 的長度和額外詢問的個數。對於樣例，$c$ 表示該樣例與測試點 $c$ 擁有相同的限制條件。

輸入的第二行包含 $n$ 個整數 $x_1,x_2,\cdots, x_n$，描述序列 $X$。

輸入的第三行包含 $m$ 個整數 $y_1,y_2,\cdots, y_m$，描述序列 $Y$。

接下來依次描述 $q$ 組額外詢問。對於每組額外詢問：

- 輸入的第一行包含兩個整數 $k_x$ 和 $k_y$，分別表示對序列 $X$ 和 $Y$ 產生的修改個數。
- 接下來 $k_x$ 行每行包含兩個整數 $p_x, v_x$，表示將 $x_{p_x}$ 修改為 $v_x$。
- 接下來 $k_y$ 行每行包含兩個整數 $p_y, v_y$，表示將 $y_{p_y}$ 修改為 $v_y$。
:::

## Output · 輸出格式

:::en
One line: a 01 string of length $q + 1$ — the answer for the original sequences, then for each query; `1` if such $F$ and $G$ exist, otherwise `0`.
:::

:::zh
輸出一行，其中包含一個長度為 $(q+1)$ 的 `01` 序列，序列的第一個元素表示初始詢問的答案，之後 $q$ 個元素依次表示每組額外詢問的答案。對於每個詢問，如果存在滿足題目條件的序列 $F$ 和 $G$，輸出 `1`，否則輸出 `0`。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

由於 $F$ 和 $G$ 太長，用省略號表示重複最後一個元素直到序列長度為 $l_0$。如 $\{1,2,3,3,\cdots\}$ 表示序列從第三個元素之後都是 $3$。

以下依次描述四次詢問，其中第一次詢問為初始詢問，之後的三次為額外詢問：

1. $A = \{8,6,9\}$，$B = \{1,7,4\}$，取 $F = \{8,8,6,9,\cdots\}, G = \{1,7,4,4,\cdots\}$；
2. $A = \{8,6,0\}$，$B = \{1,7,4\}$，可以證明不存在滿足要求的方案；
3. $A = \{8,6,9\}$，$B = \{8,7,5\}$，可以證明不存在滿足要求的方案；
4. $A = \{8,8,9\}$，$B = \{7,7,4\}$，取 $F = \{8,8,9,\cdots\}, G = \{7,7,4,\cdots\}$。

**【樣例解釋 #2】**

該組樣例滿足測試點 $4$ 的條件。

**【樣例解釋 #3】**

該組樣例滿足測試點 $7$ 的條件。

**【樣例解釋 #4】**

該組樣例滿足測試點 $9$ 的條件。

**【樣例解釋 #5】**

該組樣例滿足測試點 $18$ 的條件。

**【資料範圍】**

對於所有測試資料，保證：

- $1 \le n, m \le 5 \times 10 ^ 5$；
- $0 \le q \le 60$；
- $0 \le x_i, y_i < 10 ^ 9$；
- $0 \le k_x, k_y \le 5 \times 10 ^ 5$，且所有額外詢問的 $(k_x+k_y)$ 的和不超過 $5 \times 10 ^ 5$；
- $1 \le p_x \le n$，$1 \le p_y \le m$，$0 \le v_x, v_y < 10 ^ 9$；
- 對於每組額外詢問，$p_x$ 兩兩不同，$p_y$ 兩兩不同。
