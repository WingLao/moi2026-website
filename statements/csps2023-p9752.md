## Description · 題目說明

:::en
Little Y has a combination lock with five dials. Each dial shows a digit from $0$ to $9$ and is cyclic: from $9$, one step gives $0$ or $8$.

To lock the bike, Little Y starts from the correct password and turns the lock exactly once: either one dial by some amount, or two **adjacent** dials together by the **same** amount. For example, $\tt{0\;0\;1\;1\;5}$ can become $\tt{1\;1\;1\;1\;5}$, but not $\tt{1\;2\;1\;1\;5}$.

Little Y wrote down $n$ locked states (none of them is the correct password). How many passwords are possible such that **every one** of the $n$ states can be produced from that password by this locking method?
:::

:::zh
小 Y 有一把五個撥圈的密碼鎖。如圖所示，每個撥圈上是從 $0$ 到 $9$ 的數字。每個撥圈都是從 $0$ 到 $9$ 的迴圈，即 $9$ 撥動一個位置後可以變成 $0$ 或 $8$，

![](https://cdn.luogu.com.cn/upload/image_hosting/aku4duog.png)

因為校園裡比較安全，小 Y 採用的鎖車方式是：從正確密碼開始，隨機轉動密碼鎖僅一次；每次都是以某個幅度僅轉動一個撥圈或者同時轉動兩個相鄰的撥圈。

當小 Y 選擇同時轉動兩個相鄰撥圈時，兩個撥圈轉動的幅度相同，即小 Y 可以將密碼鎖從 $\tt{0\;0\;1\;1\;5}$ 轉成 $\tt{1\;1\;1\;1\;5}$，但不會轉成 $\tt{1\;2\;1\;1\;5}$。

時間久了，小 Y 也擔心這麼鎖車的安全性，所以小 Y 記下了自己鎖車後密碼鎖的 $n$ 個狀態，注意這 $n$ 個狀態都不是正確密碼。

為了檢驗這麼鎖車的安全性，小 Y 有多少種可能的正確密碼，使得每個正確密碼都能夠按照他所採用的鎖車方式產生鎖車後密碼鎖的全部 $n$ 個狀態。
:::

## Input · 輸入格式

:::en
Line 1: a positive integer $n$, the number of recorded states.

Next $n$ lines: five integers, one lock state.
:::

:::zh
輸入的第一行包含一個正整數 $n$，表示鎖車後密碼鎖的狀態數。

接下來 $n$ 行每行包含五個整數，表示一個密碼鎖的狀態。
:::

## Output · 輸出格式

:::en
One integer: the number of possible correct passwords.
:::

:::zh
輸出一行包含一個整數，表示密碼鎖的這 $n$ 個狀態按照給定的鎖車方式能對應多少種正確密碼。
:::


## Sample Output · 範例輸出

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

一共有 $81$ 種可能的方案。

其中轉動一個撥圈的方案有 $45$ 種，轉動兩個撥圈的方案有 $36$ 種。

**【樣例 2】**

見選手目錄下的 lock/lock2.in 與 lock/lock2.ans。

**【資料範圍】**

對於所有測試資料有：$1 \leq n \leq 8$。

| 測試點 | $n\leq$ | 特殊性質 |
| :----------: | :----------: | :----------: |
| $1\sim 3$ | $1$ | 無 |
| $4\sim 5$ | $2$ | 無 |
| $6\sim 8$ | $8$ | A |
| $9\sim 10$ | $8$ | 無 |

特殊性質 A：保證所有正確密碼都可以透過僅轉動一個撥圈得到測試資料給出的 $n$ 個狀態。
