## Description · 題目說明

:::en
For a 01 string $S = s_1 \ldots s_n$ ($n \ge 3$), define $T = f(S) = t_1 \ldots t_n$:

$$t_i = \begin{cases} s_i, & i \leq 2, \\ s_i, & i \geq 3 \text{ and } s_{i-2} = 0, \\ s_{i-1}, & i \geq 3 \text{ and } s_{i-2} = 1. \end{cases}$$

$T$ is a **fixed point** if $f(T) = T$. Let $f^k(S)$ be $S$ after $k$ transformations ($f^0(S) = S$). Find the smallest natural number $k$ such that $f^k(S)$ is a fixed point (it always exists).

There are also $q$ modifications: modification $i$ flips every bit in $[l_i, r_i]$ ($0 \leftrightarrow 1$). Answer for the initial string and after each modification.
:::

:::zh
對於一個長度為 $n$ ($n \geq 3$) 的 01 串 $S = s_1 \ldots s_n$，定義變換 $T = f(S) = t_1 \ldots t_n$ 如下：

$$t_i = \begin{cases} 
s_i, & i \leq 2, \\
s_i, & i \geq 3 \text{ 且 } s_{i-2} = 0, \\
s_{i-1}, & i \geq 3 \text{ 且 } s_{i-2} = 1.
\end{cases}$$

定義變換 $f$ 的 **不動點** 如下：若 01 串 $T$ 滿足 $f(T) = T$，則稱 $T$ 為變換 $f$ 的不動點。

記 $f^k(S)$ 為 $S$ 經過 $k$ 次變換得到的串。特別地，記 $f^0(S) = S$。求最小的自然數 $k$，使得 $f^k(S)$ 為變換 $f$ 的不動點，即滿足 $f^{k+1}(S) = f^k(S)$ 的最小的自然數 $k$。可以證明，一定存在自然數 $k$ 使得 $f^k(S)$ 為變換 $f$ 的不動點。

小 Z 覺得這個問題過於簡單，因此他增加了 $q$ 次修改操作。第 $i$ ($1 \leq i \leq q$) 次修改會給定兩個正整數 $l_i, r_i$ ($1 \leq l_i \leq r_i \leq n$)，然後將區間 $[l_i, r_i]$ 內的所有原有的 0 替換為 1，所有原有的 1 替換為 0。你需要對初始時及每次修改後的字串 $S$，求出最小的自然數 $k$，使得 $f^k(S)$ 為變換 $f$ 的不動點。
:::

## Input · 輸入格式

:::en
**Multiple test cases.** Line 1: two non-negative integers $c, t$ (test id, $0$ for samples; number of cases).

Each case: a line with $n, q$; a line with the 01 string $S$; then $q$ lines with $l_i, r_i$.
:::

:::zh
**本題包含多組測試資料。**

輸入的第一行包含兩個非負整數 $c, t$，分別表示測試點編號與測試資料組數。$c = 0$ 表示該測試點為樣例。

接下來依次輸入每組測試資料，對於每組測試資料：

第一行包含兩個正整數 $n, q$，分別表示 $S$ 的長度和修改次數。

第二行包含一個長度為 $n$ 的 01 串 $S = s_1 \ldots s_n$，表示初始時的字串。

第 $i + 2$ ($1 \leq i \leq q$) 行包含兩個正整數 $l_i, r_i$，表示一次修改操作。
:::

## Output · 輸出格式

:::en
For each case, with $k_0$ the initial answer and $k_i$ the answer after modification $i$, output one line with $\oplus_{i=0}^{q} ((i + 1) \times k_i)$ ($\oplus$ is bitwise XOR).
:::

:::zh
對於每組測試資料，設初始時的答案為 $k_0$，第 $i$ ($1 \leq i \leq q$) 次修改後的答案為 $k_i$，輸出一行一個正整數，表示 $\oplus_{i=0}^{q} ((i + 1) \times k_i)$，其中 $\oplus$ 表示 **二進位制按位異或**。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
該樣例共包含兩組測試資料。

對於第一組測試資料：
- 初始時，$S = 11010$，$f(S) = 11100$，$f^2(S) = 11110$，$f^3(S) = f^4(S) = 11111$，因此 $k_0 = 3$；
- 第一次操作後，$S = 11110$，$f(S) = f^2(S) = 11111$，因此 $k_1 = 1$；
- 第二次操作後，$S = 10110$，$f(S) = f^2(S) = 10011$，因此 $k_2 = 1$。

故答案為 $\bigoplus_{i=0}^{q} ((i+1) \times k_i) = (1 \times 3) \oplus (2 \times 1) \oplus (3 \times 1) = 3 \oplus 2 \oplus 3 = 2$。

對於第二組測試資料：
- 初始時，$S = 1010100$，$k_0 = 1$；
- 第一次操作後，$S = 1010101$，$k_1 = 1$；
- 第二次操作後，$S = 1101101$，$k_2 = 5$；
- 第三次操作後，$S = 0001101$，$k_3 = 2$。

故答案為 $\bigoplus_{i=0}^{q} ((i+1) \times k_i) = (1 \times 1) \oplus (2 \times 1) \oplus (3 \times 5) \oplus (4 \times 2) = 4$。

**【資料範圍】**

設 $N, Q$ 分別為單個測試點內所有測試資料的 $n, q$ 的和。對於所有測試資料，保證：
- $1 \leq t \leq 5$;
- $3 \leq n \leq 4 \times 10^5$, $N \leq 8 \times 10^5$;
- $1 \leq q \leq 4 \times 10^5$, $Q \leq 8 \times 10^5$;
- 對於所有 $1 \leq i \leq n$, 均有 $s_i \in \{0, 1\}$;
- 對於所有 $1 \leq i \leq q$, 均有 $1 \leq l_i \leq r_i \leq n$。

特殊性質 B: 保證對於所有 $1 \leq i \leq q$, 均有 $l_i = 1$, $r_i = n$。

特殊性質 C: 保證對於所有 $1 \leq i \leq q$, 均有 $l_i = 1$, 且 $r_1 \leq r_2 \leq \cdots \leq r_q$。
