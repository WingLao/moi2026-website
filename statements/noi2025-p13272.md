## Description · 題目說明

:::en
Given integer sequences $B = [b_1, \ldots, b_n]$ and $C = [c_1, \ldots, c_n]$. For a non-negative sequence $D$, let $S(D)$ be the set of indices with $d_i = 0$, $f(D) = \sum_{i \in S(D)} b_i$ and $g(D) = \prod_{i \in S(D)} c_i$ (if $S(D)$ is empty, $f = 0$ and $g = 1$).

Little L has a **positive** sequence $A$. One operation: choose **adjacent** indices $i, j$ ($|i - j| = 1$) with $a_i \le a_j$; set $a_j \leftarrow a_j - a_i$ and $a_i \leftarrow 0$. Any number of operations (possibly none) may be done.

Let $T(A)$ be the **set of all sequences** reachable from $A$. Find $\max_{D \in T(A)} f(D)$ and $\sum_{D \in T(A)} g(D)$ modulo $1{,}000{,}000{,}007$.
:::

:::zh
給定兩個長度為 $n$ 的整數序列 $B = [b_1, \ldots, b_n]$，$C = [c_1, \ldots, c_n]$。對於長度為 $n$ 的非負整數序列 $D = [d_1, \ldots, d_n]$，設 $S(D)$ 為所有滿足 $d_i = 0$ 的下標 $i$ 的集合，定義 $f(D) = \sum_{i \in S(D)} b_i$，$g(D) = \prod_{i \in S(D)} c_i$。特別地，若 $S(D)$ 為空，則 $f(D) = 0$，$g(D) = 1$。

小 L 有一個長度為 $n$ 的 **正整數序列** $A = [a_1, \ldots, a_n]$。小 L 可以對序列 $A$ 做如下修改：

- 選擇序列 $A$ 的兩個 **相鄰** 的下標 $i, j$（即 $1 \leq i, j \leq n$ 且 $|i - j| = 1$），若 $a_i \leq a_j$，則將 $a_j$ 改為 $a_j - a_i$，同時將 $a_i$ 改為 $0$。

小 L 可以進行任意多次修改操作，也可以不進行任何修改。對於所有序列 $A$ 透過以上修改操作可以得到的序列 $D$，小 L 想求出 $f(D)$ 的最大值以及 $g(D)$ 之和，請你幫助他求出這兩個值。形式化地，記 $T(A)$ 為序列 $A$ 透過以上修改操作可以得到的 **所有序列的集合**，你需要求出 $\max_{D \in T(A)} f(D)$ 以及 $\sum_{D \in T(A)} g(D)$。其中，由於 $\sum_{D \in T(A)} g(D)$ 可能較大，你只需要求出其對 $1,000,000,007$ 取模後的結果。
:::

### 樣例 1 解釋

該樣例共包含三組測試資料。

對於第一組測試資料，可以得到以下 4 個序列：

- $D = [5, 6, 6]$，$f(D) = 0$，$g(D) = 1$；
- $D = [0, 1, 6]$，$f(D) = 3$，$g(D) = 1$；
- $D = [5, 0, 0]$，$f(D) = 6 + 9 = 15$，$g(D) = 2 \times 3 = 6$；
- $D = [0, 0, 5]$，$f(D) = 3 + 6 = 9$，$g(D) = 1 \times 2 = 2$。

故 $\max_{D \in T(A)} f(D) = \max\{0, 3, 15, 9\} = 15$，$\sum_{D \in T(A)} g(D) = 1 + 1 + 6 + 2 = 10$。
