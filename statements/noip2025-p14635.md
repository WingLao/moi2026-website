## Description · 題目說明

:::zh
小 X 開了一家糖果店，售賣 $n$ 種糖果，每種糖果均有無限顆。對於不同種類的糖果，小 X 採用了不同的促銷策略。具體地，對於第 $i$ ($1 \le i \le n$) 種糖果，購買第一顆的價格為 $x_i$ 元，第二顆為 $y_i$ 元，第三顆又變回 $x_i$ 元，第四顆則為 $y_i$ 元，以此類推。

小 R 帶了 $m$ 元錢買糖果。小 R 不關心糖果的種類，只想得到數量儘可能多的糖果。你需要幫助小 R 求出，$m$ 元錢能購買的糖果數量的最大值。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含兩個正整數 $n, m$，代表糖果的種類數和小 R 的錢數。

輸入的第 $i+1$ ($1 \le i \le n$) 行包含兩個正整數 $x_i, y_i$，分別表示購買第 $i$ 種糖果時第奇數顆的價格和第偶數顆的價格。
:::

## Output · 輸出格式

:::zh
輸出一行一個非負整數，表示 $m$ 元錢能購買的糖果數量的最大值。
:::
