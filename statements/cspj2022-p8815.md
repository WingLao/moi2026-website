## Description · 題目說明

:::en
In a logical expression every value is $0$ (false) or $1$ (true). Here only two operations are used, AND (`&`) and OR (`|`):

$0 \mathbin{\&} 0 = 0 \mathbin{\&} 1 = 1 \mathbin{\&} 0 = 0$, $1 \mathbin{\&} 1 = 1$;  
$0 \mathbin{|} 0 = 0$, $0 \mathbin{|} 1 = 1 \mathbin{|} 0 = 1 \mathbin{|} 1 = 1$.

Parentheses are evaluated first; `&` has higher precedence than `|`; operations of the same kind go from left to right. E.g. `0|1&0` means `0|(1&0)`, and `0&1&0|1` means `((0&1)&0)|1`.

Some compilers use **short-circuit** evaluation: in `a&b`, `a` is evaluated first and if $a = 0$ the result is $0$ without evaluating `b`; in `a|b`, if $a = 1$ the result is $1$ without evaluating `b`.

Given an expression, compute its value and count how many short-circuits of each kind happen during evaluation. A short-circuit inside a part that is itself skipped by an outer short-circuit is **not** counted: in `1|(0&1)`, the whole `1|(0&1)` short-circuits, so `0&1` is never evaluated and does not count.
:::

:::zh
邏輯表示式是電腦科學中的重要概念和工具，包含邏輯值、邏輯運算、邏輯運算優先順序等內容。

在一個邏輯表示式中，元素的值只有兩種可能：$0$（表示假）和 $1$（表示真）。元素之間有多種可能的邏輯運算，本題中只需考慮如下兩種：“與”（符號為 `&`）和“或”（符號為 `|`）。其運算規則如下：

$0 \mathbin{\&} 0 = 0 \mathbin{\&} 1 = 1 \mathbin{\&} 0 = 0$，$1 \mathbin{\&} 1 = 1$；  
$0 \mathbin{|} 0 = 0$，$0 \mathbin{|} 1 = 1 \mathbin{|} 0 = 1 \mathbin{|} 1 = 1$。

在一個邏輯表示式中還可能有括號。規定在運算時，括號內的部分先運算；兩種運算並列時，`&` 運算優先於 `|` 運算；同種運算並列時，從左向右運算。

比如，表示式 `0|1&0` 的運算順序等同於 `0|(1&0)`；表示式 `0&1&0|1` 的運算順序等同於 `((0&1)&0)|1`。

此外，在 C++ 等語言的有些編譯器中，對邏輯表示式的計算會採用一種“短路”的策略：在形如 `a&b` 的邏輯表示式中，會先計算 `a` 部分的值，如果 $a = 0$，那麼整個邏輯表示式的值就一定為 $0$，故無需再計算 `b` 部分的值；同理，在形如 `a|b` 的邏輯表示式中，會先計算 `a` 部分的值，如果 $a = 1$，那麼整個邏輯表示式的值就一定為 $1$，無需再計算 `b` 部分的值。

現在給你一個邏輯表示式，你需要計算出它的值，並且統計出在計算過程中，兩種型別的“短路”各出現了多少次。需要注意的是，如果某處“短路”包含在更外層被“短路”的部分內則不被統計，如表示式 `1|(0&1)` 中，儘管 `0&1` 是一處“短路”，但由於外層的 `1|(0&1)` 本身就是一處“短路”，無需再計算 `0&1` 部分的值，因此不應當把這裡的 `0&1` 計入一處“短路”。
:::
