## Description · 題目說明

:::en
A rooted tree has $n$ nodes; node $1$ is the root and node $i$ ($2 \le i \le n$) has parent $p_i$. The **depth** $d_i$ is the number of **edges** from node $1$ to node $i$ ($d_1 = 0$). The tree's **height** $h = \max d_i$ is at most the given bound $m$.

Assign a **non-negative integer** weight $a_i$ to every node. Let $S_i$ be the set of weights in the **subtree** of $i$. The tree's **value** is $\sum_{i=1}^{n} \mathrm{mex}(S_i)$, where $\mathrm{mex}(S)$ is the smallest non-negative integer **not** in $S$. (Example in the Chinese statement: $a = (3, 2, 0, 0, 1)$ gives value $4 + 3 + 1 + 1 + 0 = 9$.)

Find the maximum value over all weight assignments.
:::

:::zh
給定一棵 $n$ 個結點的有根樹，其中結點 $1$ 為根，結點 $i$ ($2 \le i \le n$) 的父親結點為結點 $p_i$。

對於 $1 \le i \le n$，定義結點 $i$ 的**深度** $d_i$ 為結點 1 到結點 $i$ 的簡單路徑的**邊數**，也就是說，$d_1 = 0$，$d_i = d_{p_i} + 1$ ($2 \le i \le n$)。定義有根樹的**高度** $h$ 為所有結點的**深度**的**最大值**，即 $h = \max_{i=1}^{n} d_i$。

給定高度的上界 $m$。在本題中，給定的有根樹的高度不超過 $m$。

你需要給每個結點設定一個**非負整數**作為它的**權值**。對於 $1 \le i \le n$，若結點 $i$ 的權值為 $a_i$，令 $S_i$ 表示結點 $i$ 的**子樹**中結點權值構成的集合。對於每一種權值設定方案，定義樹的**價值**為 $\sum_{i=1}^{n} \mathrm{mex}(S_i)$，其中 $\mathrm{mex}(S)$ 表示**不在**集合 $S$ 中的**最小非負整數**。例如，在下圖中，若設定 $a_1 = 3$，$a_2 = 2$，$a_3 = a_4 = 0$，$a_5 = 1$，則 $S_1 = \{0,1,2,3\}$，$S_2 = \{0,1,2\}$，$S_3 = \{0\}$，$S_4 = \{0\}$，$S_5 = \{1\}$，樹的價值為 $4 + 3 + 1 + 1 + 0 = 9$。

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/w66oxx87.png)
:::

你需要求出，在所有權值設定方案中，樹的價值的最大值。
:::
