## Description · 題目說明

:::en
Little K sends Little P an **01 string** of length $8$ for a number game. Little P wants to know how many $1$s the string contains.

Note: an 01 string is a string in which every character is $0$ or $1$; for example `101` is an 01 string of length $3$.
:::

:::zh
小 K 同學向小 P 同學傳送了一個長度為 $8$ 的 **01 字串**來玩數字遊戲，小 P 同學想要知道字串中究竟有多少個 $1$。

注意：01 字串為每一個字元是 $0$ 或者 $1$ 的字串，如 `101` 為一個長度為 $3$ 的 01 字串。
:::

## Input · 輸入格式

:::en
One line: an 01 string $s$ of length $8$.
:::

:::zh
輸入檔案只有一行，一個長度為 $8$ 的 01 字串 $s$。
:::

## Output · 輸出格式

:::en
One line with one integer: the number of **characters $\mathbf 1$** in the string.
:::

:::zh
輸出檔案只有一行，包含一個整數，即 01 字串中**字元 $\mathbf 1$** 的個數。
:::

## Sample Input 1 · 範例輸入 1

```text
00010100
```

## Sample Output 1 · 範例輸出 1

```text
2
```

## Sample Input 2 · 範例輸入 2

```text
11111111
```

## Sample Output 2 · 範例輸出 2

```text
8
```

## Notes and Constraints · 說明與數據範圍

:::zh
**樣例 1 說明**

該 01 字串中有 $2$ 個字元 $1$。 


**樣例 2 說明**

該 01 字串中有 $8$ 個字元 $1$。

**資料規模與約定** 

- 對於 $20\%$ 的資料，保證輸入的字元全部為 $0$。
- 對於 $100\%$ 的資料，輸入只可能包含字元 $0$ 和字元 $1$，字串長度固定為 $8$。
:::
