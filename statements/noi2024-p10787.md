## Description · 題目說明

:::en
A tree has $n$ vertices; edge $i$ joins $u_i$ and $v_i$. Orient every edge; an orientation is a string $S = s_1 \ldots s_{n-1}$ where $s_i = 0$ means $u_i \to v_i$ and $s_i = 1$ means $v_i \to u_i$.

Given $m$ pairs $(a_i, b_i)$ ($a_i \ne b_i$), an orientation is **perfect** if no $a_i$ **can reach** $b_i$. Find the lexicographically smallest perfect orientation. **At least one exists.**
:::

:::zh
給定一棵含有 $n$ 個頂點的樹，頂點從 $1$ 到 $n$ 編號，樹上第 $i(1\leq i\leq n-1)$ 條邊連線頂點 $u_i$ 和 $v_i$。

現在，我們想要給樹的每條邊一個定向。任何一個定向都可以用一個長度為 $n-1$ 的字串 $S=s_1s_2\ldots s_{n-1}$ 來描述。其中 $s_i=0$ 代表第 $i$ 條邊定向為 $u_i \to v_i$，否則 $s_i=1$ 代表第 $i$ 條邊定向為 $v_i\to u_i$。

給定 $m$ 個頂點對 $(a_i,b_i)$，其中 $1\leq a_i,b_i \leq n$ 且 $a_i\neq b_i$。

一個**完美定向**定義為：在此定向下，對於任意 $1\leq i\leq m$，$a_i$ ****不能到達**** $b_i$。

試求在所有完美定向中，所對應的字串字典序最小的定向。**資料保證存在至少一個完美定向**。

定義字串 $S=s_1s_2\ldots s_{n-1}$ 的字典序小於 $T=t_1t_2\ldots t_{n-1}$ 若存在一個下標 $k$ 使得 $s_1=t_1, s_2=t_2, \ldots, s_{k-1}=t_{k-1}$ 且 $s_k < t_k$。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

在該樣例中，若 $S=000$，則該定向中 $1$ 能到達 $4$（存在路徑 $1\to 2\to 3\to 4$），因而不是完美定向。若 $S=001$，則該定向中 $3$ 不能到達 $2$，$1$ 不能到達 $4$，因面是完美定向。故答案為 $001$。

**【樣例 2 解釋】**

在該樣例中，一組完美定向必定滿足 $4$ 不能到達 $3$，$5$ 不能到達 $1$。故 $s_1=s_5=1$。若 $s_2=s_3=0$，則存在路徑 $1\to 2\to 3\to 4$，故 $1$ 可到達 $4$。故其不是完美定向。因此，所有完美定向必定滿足 $S$ 的字典序不小於 $10101$。且容易驗證 $S=10101$ 時，對應的定向是完美定向。

**【資料範圍】**

對於所有測試資料保證 $2\leq n\leq 5\times 10^5$，$1\leq m\leq 5\times 10^5$，$1\leq u_i,v_i\leq n$ 且所有的邊構成了一棵樹，$1\leq a_i,b_i \leq n$ 且 $a_i\neq b_i$。

資料保證存在至少一個完美定向。

::cute-table{tuack}

| 測試點編號 | $n$ | $m$ | 特殊性質 |
| :----------: | :----------: | :----------: | :----------: |
| $1\sim 3$ | $\leq 15$ | $\leq 50$ | 無 |
| $4\sim 6$ | $\leq 300$ | $\leq 300$ | 無 |
| $7,8$ | $\leq 400$ | $=(n-1)(n-2)$ | A |
| $9,10$ | $\leq 2\,000$ | $\leq 2\,000$ | B |
| $11\sim 14$ | $\leq 2\,000$ | $\leq 2\,000$ | 無 |
| $15,16$ | $\leq 10^5$ | $\leq 10^5$ | B |
| $17,18$ | $\leq 10^5$ | $\leq 10^5$ | 無 |
| $19\sim 21$ | $\leq 2\times 10^5$ | $\leq 2\times 10^5$ | 無 |
| $22\sim 25$ | $\leq 5\times 10^5$ | $\leq 5\times 10^5$ | 無 |

- 特殊性質 A：保證 $(a,b)$ 出現在 $(a_i,b_i)$ 中當且僅當 $a\neq b$ 且 $a,b$ 在樹上不相鄰。
- 特殊性質 B：保證樹上編號為 $1$ 的頂點與其他每個頂點均相鄰。
:::
