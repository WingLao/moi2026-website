## Description · 題目說明

:::en
The game has a deck and $n$ stacks whose **bottom** elements can also be removed. The deck has $m$ cards, top to bottom $a_1, \ldots, a_m$, with $k$ patterns numbered $1 \sim k$; every pattern appears an even number of times. All stacks start empty. Two operations:

1. Choose a stack and put the top card of the deck on top of it. If the top two cards of that stack now have the same pattern, both are removed automatically.
2. Choose two different stacks. If their **bottom** cards have the same pattern, both are removed (the cards above become the new bottoms); otherwise nothing happens.

For each of the $T$ levels, give an operation sequence that removes all cards.
:::

:::zh
小 E 喜歡上了一款叫做《喵了個喵》的遊戲。這個遊戲有一個牌堆和 $n$ 個可以從棧底刪除元素的棧，任務是要透過遊戲規則將所有的卡牌消去。開始時牌堆中有 $m$ 張卡牌，從上到下的圖案分別是 $a_1, a_2,\dots, a_m$。所有的卡牌一共有 $k$ 種圖案，從 $1$ 到 $k$ 編號。牌堆中每一種圖案的卡牌都有偶數張。開始時所有的棧都是空的。這個遊戲有兩種操作：

- 選擇一個棧，將牌堆頂上的卡牌放入棧的頂部。如果這麼操作後，這個棧最上方的兩張牌有相同的圖案，則會自動將這兩張牌消去。
- 選擇兩個不同的棧，如果這兩個棧棧**底**的卡牌有相同的圖案，則可以將這兩張牌消去，原來在棧底上方的卡牌會成為新的棧底。如果不同，則什麼也不會做。

這個遊戲一共有 $T$ 關，小 E 一直無法通關。請你幫小 E 設計一下游戲方案，即對於遊戲的每一關，給出相應的操作序列使得小 E 可以把所有的卡牌消去。
:::

## Input · 輸入格式

:::en
Line 1: a positive integer $T$.

Each case: a line with $n, m, k$; a line with $a_1, \ldots, a_m$. A solution is guaranteed to exist.
:::

:::zh
第一行包含一個正整數 $T$，表示資料組數。

接下來一共 $T$ 組資料，在每組資料中：

第一行包含三個正整數 $n, m, k$，分別表示棧的個數、卡牌的個數、卡牌上圖案的種類。

第二行包含 $m$ 個正整數，分別表示 $a_1, a_2,\dots, a_m$，分別從上到下表示牌堆中卡牌的圖案。

輸入資料保證有解。
:::

## Output · 輸出格式

:::en
For each case: a line with the number of operations $\mathrm{op}$ ($m \le \mathrm{op} \le 2m$), then $\mathrm{op}$ lines: `1 s` for operation 1 on stack $s$, or `2 s1 s2` for operation 2 on stacks $s_1 \ne s_2$ ($1 \le s, s_1, s_2 \le n$).
:::

:::zh
對於每一組資料，輸出若干行。

其中第一行包含一個正整數 $\mathrm{op}$，表示操作的次數。你需要保證 $m \leq \mathrm{op} \leq 2\times m$。

接下來 $\mathrm{op}$ 行，每行包含兩個或三個正整數，整數之間用一個空格隔開。

若為兩個整數 $\texttt{1 s}$，則進行一次第一個操作並選擇棧 $s$。

若為三個整數 $\texttt{2 s1 s2}$，則進行一次第二個操作並選擇棧 $s_1$ 和 $s_2$。

你需要保證 $1 \leq s, s_1, s_2 \leq n$，且 $s_1 \neq s_2$。
:::
