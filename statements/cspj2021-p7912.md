## Description · 題目說明

:::en
Little Bear's fruit shop has $n$ fruits in a row, numbered $1, 2, \ldots, n$ from left to right; each is an apple or an orange. A maximal run of consecutive fruits of the same kind is a "block". Little Bear fills baskets like this: each time, take the **leftmost** fruit of **every** block at the same time to form one basket. Repeat until no fruit is left. After each basket the blocks may change — e.g. if the only orange between two apple blocks is taken, the two apple blocks merge. Output the fruits in each basket.
:::

:::zh
小熊的水果店裡擺放著一排 $n$ 個水果。每個水果只可能是蘋果或桔子，從左到右依次用正整數 $1, 2, \ldots, n$ 編號。連續排在一起的同一種水果稱為一個“塊”。小熊要把這一排水果挑到若干個果籃裡，具體方法是：每次都把每一個“塊”中最左邊的水果同時挑出，組成一個果籃。重複這一操作，直至水果用完。注意，每次挑完一個果籃後，“塊”可能會發生變化。比如兩個蘋果“塊”之間的唯一桔子被挑走後，兩個蘋果“塊”就變成了一個“塊”。請幫小熊計算每個果籃裡包含的水果。
:::

## Input · 輸入格式

:::en
Line 1: a positive integer $n$.

Line 2: $n$ integers; the $i$-th is the kind of fruit $i$: $1$ = apple, $0$ = orange.
:::

:::zh
第一行，包含一個正整數 $n$，表示水果的數量。

第二行，包含 $n$ 個空格分隔的整數，其中第 $i$ 個數表示編號為 $i$ 的水果的種類，$1$ 代表蘋果，$0$ 代表桔子。
:::

## Output · 輸出格式

:::en
Several lines; line $i$ lists the fruits in the $i$-th basket in increasing order, separated by spaces.
:::

:::zh
輸出若干行。

第 $i$ 行表示第 $i$ 次挑出的水果組成的果籃。從小到大排序輸出該果籃中所有水果的編號，每兩個編號之間用一個空格分隔。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

這是第一組資料的樣例說明。

所有水果一開始的情況是 $[1, 1, 0, 0, 1, 1, 1, 0, 1, 1, 0, 0]$，一共有 $6$ 個塊。

在第一次挑水果組成果籃的過程中，編號為 $1, 3, 5, 8, 9, 11$ 的水果被挑了出來。

之後剩下的水果是 $[1, 0, 1, 1, 1, 0]$，一共 $4$ 個塊。

在第二次挑水果組成果籃的過程中，編號為 $2, 4, 6, 12$ 的水果被挑了出來。

之後剩下的水果是 $[1, 1]$，只有 $1$ 個塊。

在第三次挑水果組成果籃的過程中，編號為 $7$ 的水果被挑了出來。

最後剩下的水果是 $[1]$，只有 $1$ 個塊。

在第四次挑水果組成果籃的過程中，編號為 $10$ 的水果被挑了出來。

**【資料範圍】**

對於 $10 \%$ 的資料，$n \le 5$。  
對於 $30 \%$ 的資料，$n \le 1000$。  
對於 $70 \%$ 的資料，$n \le 50000$。  
對於 $100 \%$ 的資料，$1 \le n \le 2 \times {10}^5$。

**【提示】**

由於資料規模較大，建議 C/C++ 選手使用 `scanf` 和 `printf` 語句輸入、輸出。
