## Description · 題目說明

:::en
Read some integers. Print the pair with the smallest absolute difference, and that difference.
:::

:::zh
讀入一些整數，輸出相差（絕對值）最小的一對數，以及它們的差。
:::

## Input · 輸入格式

:::en
One line of integers separated by spaces.
:::

:::zh
一行整數，以空格分隔。
:::

## Output · 輸出格式

:::en
Two lines: `Pair: (a, b)` with the smaller number first; `Difference:` and the difference.
:::

:::zh
兩行：`Pair: (a, b)`，小的數在前；`Difference:` 和差。
:::

## Sample Input · 範例輸入

```text
8 3 15 10 12
```

## Sample Output · 範例輸出

```text
Pair: (10, 12)
Difference: 2
```

## Hints · 提示

:::en
- After sorting, the closest pair is always next to each other.
:::

:::zh
- 排序之後，差最小的一對一定相鄰。
:::

## Constraints · 限制

:::en
- Language: Python 3 or C++17.
- Your output must match the sample output exactly, including labels such as `Sum:` and every space.
:::

:::zh
- 語言：Python 3 或 C++17。
- 輸出必須和範例輸出完全一樣，包括 `Sum:` 之類的標籤和每一個空格。
:::
