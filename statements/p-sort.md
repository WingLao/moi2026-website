<!-- bilingual -->
## Description · 題目說明

:::en
Read N integers and print them in ascending order.
:::

:::zh
讀入 N 個整數，由小到大輸出。
:::

## Input · 輸入格式

:::en
Line 1: an integer N.

Line 2: N integers.
:::

:::zh
第 1 行：一個整數 N。

第 2 行：N 個整數。
:::

## Output · 輸出格式

:::en
One line: the integers in ascending order, separated by spaces.
:::

:::zh
一行：由小到大排好的整數，以空格分隔。
:::

## Sample Input · 範例輸入

```text
5
5 1 4 2 3
```

## Sample Output · 範例輸出

```text
1 2 3 4 5
```

## Constraints · 限制

:::en
- 1 ≤ N ≤ 1000
- -10^9 ≤ Ai ≤ 10^9
:::

:::zh
- 1 ≤ N ≤ 1000
- -10^9 ≤ Ai ≤ 10^9
:::
