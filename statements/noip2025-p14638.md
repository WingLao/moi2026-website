## Description · 題目說明

:::zh
給定一個長度為 $n$ 的整數序列 $a_1, a_2, \ldots, a_n$。

有 $q$ 次詢問，其中第 $j$ ($1 \le j \le q$) 次詢問將會給出 $L_j, R_j$ ($1 \le L_j \le R_j \le n$)。定義區間 $[l, r]$ ($1 \le l \le r \le n$) 是**極好的**，當且僅當區間 $[l, r]$ 的長度在 $[L_j, R_j]$ 內，即 $L_j \le r - l + 1 \le R_j$。定義區間 $[l, r]$ ($1 \le l \le r \le n$) 的**權值**為 $\sum_{i=l}^{r} a_i$。對於所有 $i = 1, 2, \ldots, n$，求出所有**包含** $i$ 的極好區間的最大權值，即 $\max_{1 \le l \le i \le r \le n} \{ \sum_{i=l}^{r} a_i \mid L_j \le r - l + 1 \le R_j \}$。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含一個正整數 $n$，表示序列長度。

輸入的第二行包含 $n$ 個整數 $a_1, a_2, \ldots, a_n$。

輸入的第三行包含一個正整數 $q$，表示詢問次數。

輸入的第 $j + 3$ ($1 \le j \le q$) 行包含兩個正整數 $L_j, R_j$，表示第 $j$ 次詢問。
:::

## Output · 輸出格式

:::zh
對於每次詢問，設包含 $i$ ($1 \le i \le n$) 的極好區間的最大權值為 $k_i$，輸出一行一個非負整數，表示 $\bigoplus_{i=1}^{n} \left( (i \times k_i) \bmod 2^{64} \right)$，其中 $\oplus$ 表示**二進位制按位異或**。注意：對於任意**整數** $x$，存在**唯一的非負整數** $x'$ 滿足 $x' \equiv x \pmod{2^{64}}$ 且 $0 \le x' \le 2^{64} - 1$，則記 $x \bmod 2^{64} = x'$。
:::

### 【樣例 1 解釋】

對於第 $1$ 次詢問：
- 包含 $1$ 的極好區間為 $[1,1]$ 和 $[1,2]$，權值分別為 $2,6$；
- 包含 $2$ 的極好區間為 $[1,2]$，$[2,2]$ 和 $[2,3]$，權值分別為 $6,4,-1$；
- 包含 $3$ 的極好區間為 $[2,3]$，$[3,3]$ 和 $[3,4]$，權值分別為 $-1,-5,-4$；
- 包含 $4$ 的極好區間為 $[3,4]$ 和 $[4,4]$，權值分別為 $-4,1$。

因此 $k_1 = 6$，$k_2 = 6$，$k_3 = -1$，$k_4 = 1$。

對於第 2 次詢問，$k_1 = 2$，$k_2 = 2$，$k_3 = 2$，$k_4 = 2$。

對於第 3 次詢問，$k_1 = 6$，$k_2 = 6$，$k_3 = 2$，$k_4 = 2$。
