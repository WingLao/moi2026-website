## Description · 題目說明

:::en
Little Y's bank has $N$ customers numbered $0$ to $N-1$. Customer $i$ has $W_i$ dollars, and **all amounts are different**.

Little P wants to know which customer has the most money. He cannot see the amounts, but he can send several **requests**. Each request contains several **queries**; a query is a pair $(i, j)$ asking which of customers $i$ and $j$ has more money. If $W_i > W_j$ the answer is $i$, otherwise $j$.

The number of requests $t$ and the total number of queries $s$ over all requests are limited. Write a program that finds the richest customer.
:::

:::zh
小 Y 的銀行有 $N$ 個客戶，編號為 $0$ 到 $N-1$。客戶 $i$ 有 $W_i$ 元存款，且**客戶之間的存款金額互不相同**。

小 P 希望知道哪個客戶的存款最多。他無法直接取得存款金額，但可以依次發送若干次**請求**，每次請求包含若干個**查詢**；每個查詢是一個二元組 $(i,j)$，表示想知道客戶 $i$ 和客戶 $j$ 誰的存款較多。如果 $W_i>W_j$，回答 $i$，否則回答 $j$。

小 P 的**請求數** $t$ 和所有請求的**查詢**總數 $s$ 有上限。請寫程式找出存款最多的客戶。
:::

## What to implement · 要實作的函式

:::en
Include the header at the top of your program:

```cpp
#include "richest.h"
```

Implement

```cpp
int richest(int N, int T, int S);
```

- $N$ is the number of customers;
- in this call, the number of requests $t$ must not exceed $T$;
- in this call, the total number of queries $s$ must not exceed $S$;
- return the number of the richest customer;
- **the grader calls this function exactly $10$ times per test.**

Send one **request** by calling

```cpp
std::vector<int> ask(std::vector<int> a, std::vector<int> b);
```

- $a$ and $b$ must have the same length, and every element must be in $[0, N)$; the pairs $(a[k], b[k])$ are the queries of this request;
- it returns $c$ of the same length, where $c[k]$ is whichever of $a[k]$ and $b[k]$ has more money.

Within the limits, the grader itself takes at most $3$ seconds and at most $256$ MiB.
:::

:::zh
在程式開頭加入：

```cpp
#include "richest.h"
```

實作函式

```cpp
int richest(int N, int T, int S);
```

- $N$ 是客戶數量；
- 本次呼叫中，**請求**數 $t$ 不可超過 $T$；
- 本次呼叫中，所有請求的**查詢**總數 $s$ 不可超過 $S$；
- 回傳存款最多的客戶編號；
- **每個測試點中，交互庫會呼叫此函式恰好 $10$ 次。**

呼叫以下函式來發送一次**請求**：

```cpp
std::vector<int> ask(std::vector<int> a, std::vector<int> b);
```

- $a$ 和 $b$ 長度必須相同，每個元素都必須是小於 $N$ 的非負整數；$(a[k], b[k])$ 就是這次請求中的各個查詢；
- 回傳長度相同的 $c$，$c[k]$ 是 $a[k]$ 和 $b[k]$ 中存款較多的那位客戶的編號。

在題目限制內，交互庫本身執行不超過 $3$ 秒、記憶體不超過 $256$ MiB。
:::

## Example · 範例

:::en
Suppose $N=4$, $W=[101,103,102,100]$, $T=100$, $S=100$:

| Your program | Grader | Meaning |
| :-: | :-: | :-: |
| | calls `richest(4,100,100)` | start |
| calls `ask([0,2],[1,3])` | returns $[1,2]$ | $W_0<W_1$, $W_2>W_3$ |
| calls `ask([0,2,3],[1,1,1])` | returns $[1,1,1]$ | $W_0,W_2,W_3<W_1$ |
| returns $1$ | prints the result | correct |

Here $t=2$ and $s=5$ are within the limits.
:::

## Subtasks and scoring · 測試點與計分

:::en
| Test | Points | $N$ | $T$ | $S$ |
| :-: | :-: | :-: | :-: | :-: |
| 1 | 15 | $1\,000$ | $1$ | $499\,500$ |
| 2 | 85 | $1\,000\,000$ | $20$ | $2\,000\,000$ |

Exceeding $T$ or $S$, an invalid `ask`, or a wrong answer in any of the 10 calls gives $0$ for that test. In test 1 a correct program gets full marks. In test 2, with $\max t$ and $\max s$ the largest values over the 10 calls, the score is $\lfloor 85 \cdot f(\max t) \cdot g(\max s)\rfloor$:

- $f = 1$ if $\max t \le 8$; otherwise $f = 1-\frac{1}{4}\sqrt{\max t-8}$.
- $g = 1$ if $\max s \le 1\,099\,944$; $g = 1-\frac{1}{6}\log_{10}(\max s-1\,099\,943)$ if $\max s \le 1\,100\,043$; otherwise $g = \frac{2}{3}-\frac{1}{1\,500}\sqrt{\max s-1\,100\,043}$.

**The grader may be adaptive:** it can change $W$ during the run as long as it stays consistent with all earlier answers. Do not rely on how the grader works, and do not try to read its data.
:::

:::zh
| 測試點 | 分值 | $N$ | $T$ | $S$ |
| :-: | :-: | :-: | :-: | :-: |
| 1 | 15 | $1\,000$ | $1$ | $499\,500$ |
| 2 | 85 | $1\,000\,000$ | $20$ | $2\,000\,000$ |

10 次呼叫中任何一次超過 $T$ 或 $S$、`ask` 不合法或答案錯誤，該測試點得 $0$ 分。測試點 1 答對即得滿分。測試點 2 中，設 $\max t$、$\max s$ 為 10 次呼叫中的最大值，得分為 $\lfloor 85 \cdot f(\max t) \cdot g(\max s)\rfloor$：

- $\max t \le 8$ 時 $f = 1$，否則 $f = 1-\frac{1}{4}\sqrt{\max t-8}$。
- $\max s \le 1\,099\,944$ 時 $g = 1$；$\max s \le 1\,100\,043$ 時 $g = 1-\frac{1}{6}\log_{10}(\max s-1\,099\,943)$；否則 $g = \frac{2}{3}-\frac{1}{1\,500}\sqrt{\max s-1\,100\,043}$。

例如 $\max t=20$ 時最多 11 分，$\max t=10$ 時最多 54 分，$\max t \le 8$ 且 $\max s \le 1\,099\,944$ 才是 85 分。

**交互庫可能是適應性的**：只要不與先前 `ask` 的回答矛盾，它可以在執行中調整 $W$。不要依賴交互庫的實作，也不要嘗試讀取它的資料。
:::
