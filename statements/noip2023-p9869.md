## Description · 題目說明

:::en
In Kleene three-valued logic a variable is True ($T$), False ($F$) or Unknown ($U$). Negation: $\lnot T = F$, $\lnot F = T$, $\lnot U = U$.

There are $n$ variables $x_1, \ldots, x_n$ and $m$ statements run in order ($\leftarrow$ is assignment):

1. $x_i \leftarrow v$ with $v \in \{T, F, U\}$;
2. $x_i \leftarrow x_j$;
3. $x_i \leftarrow \lnot x_j$.

Choose initial values so that after all statements every variable equals its initial value, using as **few** $U$ initial values as possible. Such an assignment always exists. Output the minimum number of $U$.
:::

:::zh
小 L 今天學習了 Kleene 三值邏輯。

在三值邏輯中，一個變數的值可能為：真（$\mathit{True}$，簡寫作 $\mathit{T}$）、假（$\mathit{False}$，簡寫作 $\mathit{F}$）或未確定（$\mathit{Unknown}$，簡寫作 $\mathit{U}$）。

在三值邏輯上也可以定義邏輯運算。由於小 L 學習進度很慢，只掌握了邏輯非運算 $\lnot$，其運演算法則為：
$$\lnot \mathit{T} = \mathit{F}, \lnot \mathit{F} = \mathit{T}, \lnot\mathit{U} = \mathit{U}.$$

現在小 L 有 $n$ 個三值邏輯變數 $x_1,\cdots, x_n$。小 L 想進行一些有趣的嘗試，於是他寫下了 $m$ 條語句。語句有以下三種型別，其中 $\leftarrow$ 表示賦值：

1. $x_i \leftarrow v$，其中 $v$ 為 $\mathit{T}, \mathit{F}, \mathit{U}$ 的一種；
2. $x_i \leftarrow x_j$；
3. $x_i \leftarrow \lnot x_j$。

一開始，小 L 會給這些變數賦初值，然後按順序執行這 $m$ 條語句。

小 L 希望執行了所有語句後，所有變數的最終值與初值都相等。在此前提下，小 L 希望初值中 $\mathit{Unknown}$ 的變數儘可能少。

在本題中，你需要幫助小 L 找到 $\mathit{Unknown}$ 變數個數最少的賦初值方案，使得執行了所有語句後所有變數的最終值和初始值相等。小 L 保證，至少對於本題的所有測試用例，這樣的賦初值方案都必然是存在的。
:::

## Input · 輸入格式

:::en
**Each test file has several test cases.** Line 1: two integers $c, t$ (test id and number of cases).

Each case: a line with $n, m$; then $m$ statements. Each starts with a character $v$ from `TFU+-`: for `T`, `F`, `U` an integer $i$ follows ($x_i \leftarrow v$); for `+` two integers $i, j$ ($x_i \leftarrow x_j$); for `-` two integers $i, j$ ($x_i \leftarrow \lnot x_j$).
:::

:::zh
**本題的測試點包含有多組測試資料。**

輸入的第一行包含兩個整數 $c$ 和 $t$，分別表示測試點編號和測試資料組數。對於樣例，$c$ 表示該樣例與測試點 $c$ 擁有相同的限制條件。

接下來，對於每組測試資料：

- 輸入的第一行包含兩個整數 $n$ 和 $m$，分別表示變數個數和語句條數。
- 接下來 $m$ 行，按執行順序給出每條語句。
  - 輸入的第一個字元 $v$ 描述這條語句的型別。保證 $v$ 為 `TFU+-` 的其中一種。
  - 若 $v$ 為 `TFU` 的某一種時，接下來給出一個整數 $i$，表示該語句為 $x_i \leftarrow v$；
  - 若 $v$ 為 `+`，接下來給出兩個整數 $i,j$，表示該語句為 $x_i \leftarrow x_j$；
  - 若 $v$ 為 `-`，接下來給出兩個整數 $i,j$，表示該語句為 $x_i \leftarrow \lnot x_j$。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

第一組測試資料中，$m$ 行語句依次為

- $x_2 \leftarrow \lnot x_1$；
- $x_3 \leftarrow \lnot x_2$；
- $x_1 \leftarrow x_3$。

一組合法的賦初值方案為 $x_1 = \mathit{T}, x_2 = \mathit{F}, x_3 = \mathit{T}$，共有 $0$ 個 $\mathit{Unknown}$ 變數。因為不存在賦初值方案中有小於 $0$ 個 $\mathit{Unknown}$ 變數，故輸出為 $0$。

第二組測試資料中，$m$ 行語句依次為

- $x_2 \leftarrow \lnot x_1$；
- $x_3 \leftarrow \lnot x_2$；
- $x_1 \leftarrow \lnot x_3$。

唯一的賦初值方案為 $x_1 = x_2 = x_3 = \mathit{U}$，共有 $3$ 個 $\mathit{Unknown}$ 變數，故輸出為 $3$。

第三組測試資料中，$m$ 行語句依次為

- $x_2 \leftarrow \mathit{T}$；
- $x_2 \leftarrow \mathit{U}$；

一個最小化 $\mathit{Unknown}$ 變數個數的賦初值方案為 $x_1 = \mathit{T}, x_2 = \mathit{U}$。$x_1 = x_2 = \mathit{U}$ 也是一個合法的方案，但它沒有最小化 $\mathit{Unknown}$ 變數的個數。
