## Background · 題目背景

:::zh
在 C++ 等高階語言中，除了 int 和 float 等基本型別外，通常還可以自定義結構體型別。在本題當中，你需要模擬一種類似 C++ 的高階語言的結構體定義方式，並計算出相應的記憶體佔用等資訊。
:::

## Description · 題目說明

:::en
Simulate struct definitions of a C++-like language and compute memory layout.

There are $4$ basic types: `byte`, `short`, `int`, `long`, of sizes $1, 2, 4, 8$ bytes.

A struct **type** has a type name and members, each with a type (basic, or a struct type **defined earlier**) and a name, in order. Defining a type does not use memory.

An **element** has a type and a name. Memory rules:

- members are laid out in the **order they were defined** (recursively for struct members);
- **alignment**: the size of every type and the start address of every element must be a multiple of the type's alignment. A basic type's alignment equals its size; a struct's alignment is the **maximum** alignment of its members.

Example: `struct d { short a; int b; short c; }; d e;` — `e.a`, `e.b`, `e.c` occupy bytes $0 \sim 1$, $4 \sim 7$, $8 \sim 9$; since `d` aligns to $4$, `e` occupies $0 \sim 11$ and has size $12$.

Process $n$ operations:

1. Define a struct type with name $s$ and $k$ members $(t_i, n_i)$. Output its size and alignment, separated by a space.
2. Define an element of type $t$ and name $n$. Elements are placed in order from address $0$, obeying alignment. Output its start address.
3. Access an element $s$ such as `a.b.c` (`.` accesses members). Output the start address of the **innermost** element.
4. Access address $addr$. If some element of a **basic type** occupies it, output that element in the format of operation 3; otherwise output `ERR`.
:::

:::zh
在這種語言中，基本型別共有 $4$ 種：`byte`、`short`、`int`、`long`，分別佔據 $1$、$2$、$4$、$8$ 位元組的空間。

定義一個結構體**型別**時，需要給出**型別名**和**成員**，其中每個成員需要按順序給出**型別**和**名稱**。型別可以為基本型別，也可以為**先前定義過**的結構體型別。注意，定義結構體**型別**時不會定義具體元素，即不佔用記憶體。

定義一個**元素**時，需要給出元素的**型別**和**名稱**。元素將按照以下規則佔據記憶體：

- 元素內的所有成員將按照**定義時給出的順序**在記憶體中排布，對於型別為結構體的成員同理。
- 為了保證記憶體訪問的效率，元素的地址佔用需要滿足**對齊規則**，即任何型別的**大小**和該型別元素在記憶體中的**起始地址**均應對齊到該型別對齊要求的**整數倍**。具體而言：
  - 對於基本型別：對齊要求等於其佔據空間大小，如 `int` 型別需要對齊到 $4$ 位元組，其餘同理。
  - 對於結構體型別：對齊要求等於其成員的對齊要求的**最大值**，如一個含有 `int` 和 `short` 的結構體型別需要對齊到 $4$ 位元組。

以下是一個例子（以 C++ 語言的格式書寫）：

```cpp
struct d {
    short a;
    int b;
    short c;
};
d e;
```

該程式碼定義了結構體型別 `d` 與元素 `e`。元素 `e` 包含三個成員 `e.a`、`e.b`、`e.c`，分別佔據第 $0 \sim 1$、$4 \sim 7$、$8 \sim 9$ 位元組的地址。由於型別 `d` 需要對齊到 $4$ 位元組，因此 `e` 佔據了第 $0 \sim 11$ 位元組的地址，大小為 $12$ 位元組。

你需要處理 $n$ 次操作，每次操作為以下四種之一：

1. 定義一個結構體型別。具體而言，給定正整數 $k$ 與字串 $s, t_1, n_1, \dots, t_k, n_k$，其中 $k$ 表示該型別的成員數量，$s$ 表示該型別的型別名，$t_1, t_2, \dots, t_k$ 按順序分別表示每個成員的型別，$n_1, n_2, \dots, n_k$ 按順序分別表示每個成員的名稱。你需要輸出該結構體型別的大小和對齊要求，用一個空格分隔。

2. 定義一個元素，具體而言，給定字串 $t, n$ 分別表示該元素的型別與名稱。所有被定義的元素將按順序，從記憶體地址為 $0$ 開始依次排開，並需要滿足地址對齊規則。你需要輸出新定義的元素的起始地址。

3. 訪問某個元素。具體而言，給定字串 $s$，表示所訪問的元素。與 C++ 等語言相同，採用 `.` 來訪問結構體型別的成員。如 `a.b.c`，表示 `a` 是一個已定義的元素，它是一個結構體型別，有一個名稱為 `b` 的成員，它也是一個結構體型別，有一個名稱為 `c` 的成員。你需要輸出如上被訪問的**最內層**元素的起始地址。

4. 訪問某個記憶體地址。具體而言，給定非負整數 $addr$，表示所訪問的地址，你需要判斷是否存在一個**基本型別**的元素佔據了該地址。若是，則按操作 3 中的訪問元素格式輸出該元素；否則輸出 `ERR`。
:::

Then each operation starts with an integer $op$:

- $op = 2$: two strings $t, n$;
- $op = 3$: a string $s$;
- $op = 4$: a non-negative integer $addr$.
:::

## Notes and Constraints · 說明與數據範圍

:::zh
#### 【樣例 1 解釋】

結構體型別 `a` 中，`short` 型別的成員 `aa` 佔據第 $0 \sim 1$ 位元組地址，`int` 型別的成員 `ab` 佔據第 $4 \sim 7$ 位元組地址。又由於其對齊要求為 $4$ 位元組，可得其大小為 $8$ 位元組。由此可同理計算出結構體型別 `b` 的大小為 $16$ 位元組，對齊要求為 $8$ 位元組。

#### 【樣例 2】

見選手目錄下的 struct/struct2.in 與 struct/struct2.ans。

#### 【樣例 2 解釋】
第二個操作 4 中，訪問的記憶體地址恰好在為了地址對齊而留下的 “洞” 裡，因此沒有基本型別元素佔據它。

#### 【樣例 3】
見選手目錄下的 struct/struct3.in 與 struct/struct3.ans。

#### 【資料範圍】
對於全部資料，滿足 $1 \le n \le 100$，$1 \le k \le 100$，$0 \le addr \le 10^{18}$。

所有定義的結構體型別名、成員名稱和定義的元素名稱均由不超過 $10$ 個字元的小寫字母組成，且都不是 `byte,short,int,long`（即不與基本型別重名）。

所有定義的結構體型別名和元素名稱互不相同，同一結構體內成員名稱互不相同。但不同的結構體可能有相同的成員名稱，某結構體內的成員名稱也可能與定義的結構體或元素名稱相同。

保證所有操作均符合題目所述的規範和要求，即結構體的定義不會包含不存在的型別、不會訪問不存在的元素或成員等。

保證任意結構體大小及定義的元素佔據的最高記憶體地址均不超過 $10^{18}$。

| 測試點 | 特殊性質 |
| :----------: | :----------: |
| $1$ | A、D |
| $2\sim 3$ | A |
| $4\sim 5$ | B、D |
| $6\sim 8$  | B |
| $9\sim 10$ | C、D|
| $11\sim 13$ | C|
| $14\sim 16$ |D|
|$17\sim 20$| 無|

特殊性質 A：沒有操作 $1$；

特殊性質 B：只有一個操作 $1$；

特殊性質 C：所有操作 $1$ 中給出的成員型別均為基本型別；

特殊性質 D：基本型別只有 `long`。

#### 【提示】

對於結構體型別的對齊要求和大小，形式化的定義方式如下：

- 設該結構體內有 $k$ 個成員，其大小分別為 $s_1,...,s_k$，對齊要求分別為 $a_1,...,a_k$;
- 則該結構體的對齊要求為 $a=\max\{a_1,...,a_k\}$；
- 再設這些成員排布時的**地址偏移量**分別為 $o_1,...,o_k$，則：
  - $o_1 = 0$;
  - 對於 $i=2,...,k$，$o_i$ 為滿足 $o_{i-1}+s_{i-1}\le o_i$ 且 $a_i$ 整除 $o_i$ 的最小值；
  - 則該結構體的大小 $s$ 為滿足 $o_k+s_k\le s$ 且 $a$ 整除 $s$ 的最小值；

對於定義元素時的記憶體排布，形式化的定義方式如下：

- 設第 $i$ 個被定義的元素大小為 $s_i$，對齊要求為 $a_i$，起始地址為 $b_i$;
- 則 $b_1 = 0$，對於 $2\le i$， $b_i$ 為滿足 $b_{i-1} + s_{i-1}\le b_i$ 且 $a_i$ 整除 $b_i$ 的最小值。
:::
