## Description · 題目說明

:::en
You are given $n$ and a sequence $a_1, a_2, \ldots, a_{2 n}$ in which each of $1, 2, \ldots, n$ appears exactly twice. You build a sequence $b_1, \ldots, b_{2 n}$, starting empty, with $2n$ operations, each one of:

1. move the **first** element of $a$ to the end of $b$;
2. move the **last** element of $a$ to the end of $b$.

The goal is for $b$ to be a **palindrome**: $b_i = b_{2 n + 1 - i}$ for all $1 \le i \le n$. Decide whether this is possible; if so, output the lexicographically smallest plan (see Output).
:::

:::zh
給定正整數 $n$ 和整數序列 $a_1, a_2, \ldots, a_{2 n}$，在這 $2 n$ 個數中，$1, 2, \ldots, n$ 分別各出現恰好 $2$ 次。現在進行 $2 n$ 次操作，目標是建立一個長度同樣為 $2 n$ 的序列 $b_1, b_2, \ldots, b_{2 n}$，初始時 $b$ 為空序列，每次可以進行以下兩種操作之一：

1. 將序列 $a$ 的開頭元素加到 $b$ 的末尾，並從 $a$ 中移除。
2. 將序列 $a$ 的末尾元素加到 $b$ 的末尾，並從 $a$ 中移除。

我們的目的是讓 $b$ 成為一個**迴文數列**，即令其滿足對所有 $1 \le i \le n$，有 $b_i = b_{2 n + 1 - i}$。請你判斷該目的是否能達成，如果可以，請輸出字典序最小的操作方案，具體在【**輸出格式**】中說明。
:::

:::en
Several test groups. Line 1: an integer $T$, the number of groups. Each group:

Line 1: a positive integer $n$.

Line 2: $2n$ integers $a_1, \ldots, a_{2 n}$.
:::

:::zh
每個測試點包含多組測試資料。

輸入的第一行，包含一個整數 $T$，表示測試資料的組數。對於每組測試資料：

第一行，包含一個正整數 $n$。  
第二行，包含 $2 n$ 個用空格隔開的整數 $a_1, a_2, \ldots, a_{2 n}$。
:::

## Output · 輸出格式

:::en
One line per group: `-1` if no palindrome can be made; otherwise a string of $2n$ characters `L` (operation 1) and `R` (operation 2), with no spaces — the lexicographically smallest among all valid plans.

String $s$ is lexicographically smaller than $t$ (both of length $2n$) if there is a $k$ with $s_i = t_i$ for all $i < k$ and $s_k < t_k$.
:::

:::zh
對每組測試資料輸出一行答案。

如果無法生成出迴文數列，輸出一行 `-1`，否則輸出一行一個長度為 $2 n$ 的、由字元 `L` 或 `R` 構成的字串（不含空格），其中 `L` 表示移除開頭元素的操作 1，`R` 表示操作 2。

你需要輸出所有方案對應的字串中字典序最小的一個。

字典序的比較規則如下：長度均為 $2 n$ 的字串 $s_{1 \sim 2 n}$ 比 $t_{1 \sim 2 n}$ 字典序小，當且僅當存在下標 $1 \le k \le 2 n$ 使得對於每個 $1 \le i < k$ 有 $s_i = t_i$ 且 $s_k < t_k$。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例解釋 #1】**

在第一組資料中，生成的的 $b$ 數列是 $[4, 5, 3, 1, 2, 2, 1, 3, 5, 4]$，可以看出這是一個迴文數列。

另一種可能的操作方案是 `LRRLLRRRRR`，但比答案方案的字典序要大。

**【資料範圍】**

令 $\sum n$ 表示所有 $T$ 組測試資料中 $n$ 的和。

對所有測試點保證 $1 \le T \le 100$，$1 \le n, \sum n \le 5 \times {10}^5$。

| 測試點編號 | $T \le$ | $n \le$ | $\sum n \le$ | 特殊性質 |
|:-:|:-:|:-:|:-:|:-:|
| $1 \sim 7$ | $10$ | $10$ | $50$ | 無 |
| $8 \sim 10$ | $100$ | $20$ | $1000$ | 無 |
| $11 \sim 12$ | $100$ | $100$ | $1000$ | 無 |
| $13 \sim 15$ | $100$ | $1000$ | $25000$ | 無 |
| $16 \sim 17$ | $1$ | $5 \times {10}^5$ | $5 \times {10}^5$ | 無 |
| $18 \sim 20$ | $100$ | $5 \times {10}^5$ | $5 \times {10}^5$ | 有 |
| $21 \sim 25$ | $100$ | $5 \times {10}^5$ | $5 \times {10}^5$ | 無 |

特殊性質：如果我們每次刪除 $a$ 中兩個相鄰且相等的數，存在一種方式將序列刪空（例如 $a = [1, 2, 2, 1]$）。
