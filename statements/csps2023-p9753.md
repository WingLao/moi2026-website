## Description · 題目說明

:::zh
小 L 現在在玩一個低配版本的消消樂，該版本的遊戲是一維的，一次也只能消除兩個相鄰的元素。

現在，他有一個長度為 $n$ 且僅由小寫字母構成的字串。我們稱一個字串是可消除的，當且僅當可以對這個字串進行若干次操作，使之成為一個空字串。

其中每次操作可以從字串中刪除兩個相鄰的相同字元，操作後剩餘字串會拼接在一起。

小 L 想知道，這個字串的所有非空連續子串中，有多少個是可消除的。
:::

**【樣例 1 解釋】**

一共有 $5$ 個可消除的連續子串，分別是 `cc`、`acca`、`cc`、`bccb`、`accabccb`。

**【樣例 2】**

**【樣例 3】**

**【樣例 4】**

見選手目錄下的 `game/game4.in` 與 `game/game4.ans`。

**【資料範圍】**

對於所有測試資料有：$1 \le n \le 2 \times 10^6$，且詢問的字串僅由小寫字母構成。

| 測試點 | $n\leq$ | 特殊性質 |
| :----------: | :----------: | :----------: |
| $1\sim 5$ | $10$ | 無 |
| $6\sim 7$ | $800$ | ^ |
| $8\sim 10$ | $8000$ | ^ |
| $11\sim 12$ | $2\times 10^5$ | A |
| $13\sim 14$ | ^ | B |
| $15\sim 17$ | ^ | 無 |
| $18\sim 20$ | $2\times 10^6$ | ^ |

特殊性質 A：字串中的每個字元獨立等機率地從字符集中選擇。

特殊性質 B：字串僅由 `a` 和 `b` 構成。
