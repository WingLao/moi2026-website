## Description · 題目說明

:::en
$n$ candies are left; candy $i$ has original price $a_i$. Each will get a clearance price $w_i \in \{1, 2\}$; its **value ratio** is $\frac{a_i}{w_i}$.

Little R has $m$ dollars and wants the largest total original price. He sorts candies by **value ratio from high to low** (ties: **higher original price** first; then smaller index first) and considers them in order, buying a candy if his remaining money is at least $w_i$, otherwise skipping it.

E.g. with $a = (1, 3, 5)$ and $w = (1, 1, 2)$, the ratios are $1, 3, \frac{5}{2}$, so he considers candy $2$, then $3$, then $1$.

Among all $2^n$ pricings, count those for which this greedy strategy achieves the **maximum possible** total original price (over all purchasable sets). Output modulo $998{,}244{,}353$.
:::

:::zh
小 X 的糖果促銷策略很成功，現在糖果店只剩下了 $n$ 顆糖果，其中第 $i$ ($1 \le i \le n$) 顆糖果的原價為 $a_i$ 元。小 X 計劃將它們全部重新定價，清倉甩賣。具體地，小 X 會將每顆糖果的清倉價格分別定為 $1$ 元或 $2$ 元。設第 $i$ ($1 \le i \le n$) 顆糖果的清倉價格為 $w_i \in \{1,2\}$ 元，則它的**價效比**被定義為原價與清倉價格的比值，即 $\frac{a_i}{w_i}$。

小 R 又帶了 $m$ 元錢買糖果。這一次，小 R 希望他購買到的糖果的原價總和最大，於是他採用了以下購買策略：將所有糖果按照**價效比從大到小排序**，然後依次考慮每一顆糖果。具體地，若小 R 在考慮第 $i$ ($1 \le i \le n$) 顆糖果時剩餘的錢至少為 $w_i$ 元，則他會購買這顆糖果；否則他會跳過這顆糖果，繼續考慮下一顆。特別地，若存在兩顆糖果的價效比相同，則小 R 會先考慮**原價較高**的糖果；若存在兩顆糖果的價效比與原價均相同，則小 R 會先考慮編號較小的糖果。

例如，若小 X 的糖果商店剩餘 $3$ 顆糖果，原價分別為 $a_1=1$，$a_2=3$，$a_3=5$，而清倉價格分別為 $w_1=w_2=1$，$w_3=2$，則價效比分別為 $1, 3, \frac{5}{2}$。因此小 R 會先考慮第 $2$ 顆糖果，然後考慮第 $3$ 顆糖果，最後考慮第 $1$ 顆糖果。

小 R 想知道，在小 X 的所有 $2^n$ 種定價方案中，有多少種定價方案使得他按照上述購買策略能購買到的糖果的**原價總和最大**。你需要幫助小 R 求出滿足要求的定價方案的數量。由於答案可能較大，你只需要求出答案對 $998,244,353$ 取模後的結果。
:::

## Input · 輸入格式

:::en
**Multiple test cases.** Line 1: two non-negative integers $c, t$ (test id, $c = 0$ for samples; number of cases).

Each case: a line with $n, m$; a line with $a_1, \ldots, a_n$.
:::

:::zh
**本題包含多組測試資料。**

輸入的第一行包含兩個非負整數 $c, t$，分別表示測試點編號與測試資料組數。$c=0$ 表示該測試點為樣例。

接下來依次輸入每組測試資料，對於每組測試資料：
- 第一行包含兩個正整數 $n, m$，分別表示糖果的數量與小 R 的錢數；
- 第二行包含 $n$ 個正整數 $a_1, a_2, \ldots, a_n$，分別表示每顆糖果的原價。
:::

### 【樣例 1 解釋】

該樣例即為【題目描述】中的例子。共有以下 $6$ 種定價方案使得小 R 購買到的糖果原價總和最大，分別為：

- $w_1 = w_2 = w_3 = 1$，小 R 購買到的糖果原價總和為 $8$；
- $w_1 = w_3 = 1$，$w_2 = 2$，小 R 購買到的糖果原價總和為 $6$；
- $w_1 = 1$，$w_2 = w_3 = 2$，小 R 購買到的糖果原價總和為 $5$；
- $w_2 = w_3 = 1$，$w_1 = 2$，小 R 購買到的糖果原價總和為 $8$；
- $w_3 = 1$，$w_1 = w_2 = 2$，小 R 購買到的糖果原價總和為 $5$；
- $w_1 = w_2 = w_3 = 2$，小 R 購買到的糖果原價總和為 $5$。

注意：若 $w_1 = w_2 = 1$，$w_3 = 2$，則小 R 會依次購買第 $2$ 顆和第 $1$ 顆糖果，原價總和為 $4$，但小 R 可以只購買第 $3$ 顆糖果，原價總和為 $5$。因此該定價方案無法使小 R 購買到的糖果的原價總和達到最大值。
