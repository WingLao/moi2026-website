## Description · 題目說明

:::en
A binary tree has $4n - 1$ nodes; every internal node has **exactly** two children. Internal nodes are numbered $1 \sim 2n - 1$ and leaves $2n \sim 4n - 1$. Initially no leaf has a number.

A DFS order (children may be visited in either order) is **beautiful** if the numbers on the **numbered leaves**, read in that DFS order, can be reduced to the empty sequence by repeatedly **deleting two adjacent equal numbers**. E.g. $[1, 2, 2, 1]$ is reducible but $[1, 2, 1, 2]$ is not (see the figure in the Chinese statement).

There are $n$ operations; operation $i$ writes the number $i$ on two **unnumbered** leaves. **After each operation at least one beautiful DFS order exists.** After each operation, output the number of beautiful DFS orders modulo $1{,}000{,}000{,}007$.
:::

:::zh
給定一棵 $4n - 1$ 個結點的二叉樹，其中每個非葉結點都有 **恰好** 兩個子結點。非葉結點編號為 $1$ 到 $2n - 1$，葉子結點編號為 $2n$ 到 $4n - 1$。初始時，每個葉子結點上都沒有數字。

定義一個 DFS 序是 **優美的**，當且僅當按該 DFS 序將 **所有標有數字的葉子結點** 上的數字拼成一個序列時，該序列可以透過若干次 **消除相鄰相同數字** 的方式得到空序列。例如，在下圖中，若葉子結點 $4, 6$ 上標有數字 $1$，葉子結點 $5, 7$ 上標有數字 $2$，則按 DFS 序 $[1, 4, 2, 7, 3, 5, 6]$ 將所有標有數字的葉子結點上的數字拼成的序列為 $[1, 2, 2, 1]$，可以透過消除相鄰的 $2$ 的方式得到 $[1, 1]$，再透過消除相鄰的 $1$ 的方式得到空序列，因此該 DFS 序是優美的；而按 DFS 序 $[1, 4, 2, 3, 5, 6, 7]$ 將所有標有數字的葉子結點上的數字拼成的序列為 $[1, 2, 1, 2]$，無法透過若干次消除相鄰相同數字的方式得到空序列，因此該 DFS 序不是優美的。

![](https://cdn.luogu.com.cn/upload/image_hosting/p4thcg8c.png)

給定 $n$ 次操作，第 $i$ ($1 \leq i \leq n$) 次操作會選擇兩個 **沒有數字** 的葉子結點，然後將這兩個結點標上數字 $i$。**保證在每次操作後，存在至少一個優美的 DFS 序**。你需要求出每次操作後的優美的 DFS 序的數量。由於答案可能較大，你只需要求出答案對 $1,000,000,007$ 取模後的結果。
:::

## Input · 輸入格式

:::en
Line 1: a non-negative integer $c$ (test id, $0$ for samples).

Line 2: a positive integer $n$ (the tree has $4n - 1$ nodes).

Next $2n - 1$ lines: line $i$ has $l_i, r_i$, the left and right children of node $i$ ($i < l_i, r_i \le 4n - 1$, all distinct).

Next $n$ lines: $a_i, b_i$, the leaves chosen by operation $i$ ($2n \le a_i, b_i \le 4n - 1$, all distinct).
:::

:::zh
輸入的第一行包含一個非負整數 $c$，表示測試點編號。$c = 0$ 表示該測試點為樣例。

輸入的第二行包含一個正整數 $n$，表示二叉樹的結點個數為 $4n - 1$。

輸入的第 $i + 2$ ($1 \leq i \leq 2n - 1$) 行包含兩個正整數 $l_i$ 和 $r_i$，分別表示結點 $i$ 的左右子結點。保證 $i < l_i, r_i \leq 4n - 1$，且所有的 $l_i, r_i$ 互不相同。

輸入的第 $i + 2n + 1$ ($1 \leq i \leq n$) 行包含兩個正整數 $a_i, b_i$，表示第 $i$ 次操作選擇的葉子結點的編號。保證 $2n \leq a_i, b_i \leq 4n - 1$，且所有的 $a_i, b_i$ 互不相同。
:::

## Output · 輸出格式

:::en
$n$ lines: the number of beautiful DFS orders after operation $i$, modulo $1{,}000{,}000{,}007$.
:::

:::zh
輸出 $n$ 行，其中第 $i$ ($1 \leq i \leq n$) 行包含一個非負整數，表示第 $i$ 次操作後的優美的 DFS 序的數量對 $1,000,000,007$ 取模後的結果。
:::

### 樣例 1 解釋

該樣例即【題目描述】中所示的例子。
- 第一次操作後，葉子結點 $4$ 和 $6$ 上標有數字 $1$，葉子結點 $5$ 和 $7$ 上沒有數字，因此按任意 DFS 序拼成的序列均為 $[1, 1]$，即所有的 $2^3 = 8$ 個 DFS 序都是優美的。

### 資料範圍

對於所有測試資料，保證：
- $1 \leq n \leq 2 \times 10^5$；
- 對於所有 $1 \leq i \leq 2n - 1$，均有 $i < l_i, r_i \leq 4n - 1$，且所有的 $l_i, r_i$ 互不相同；
- 對於所有 $1 \leq i \leq n$，均有 $2n \leq a_i, b_i \leq 4n - 1$，且所有的 $a_i, b_i$ 互不相同；
- 在每次操作後，存在至少一個優美的 DFS 序。
