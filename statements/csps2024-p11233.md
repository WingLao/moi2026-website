## Description · 題目說明

:::en
Given an array $A$ of $n$ positive integers in a row, colour each number red or blue. Then build $C$ of length $n$: for each $A_i$,

- if no number of the same colour is to its left, $C_i = 0$;
- otherwise let $A_j$ be the **nearest** same-coloured number to its left; $C_i = A_i$ if $A_i = A_j$, else $C_i = 0$.

The score is $\sum_{i=1}^n C_i$. Find the maximum possible score.
:::

:::zh
給定一個長度為 $n$ 的正整數陣列 $A$，其中所有數從左至右排成一排。

你需要將 $A$ 中的每個數染成紅色或藍色之一，然後按如下方式計算最終得分：

設 $C$ 為長度為 $n$ 的整數陣列，對於 $A$ 中的每個數 $A_i$（$1 \leq i \leq n$）：

- 如果 $A_i$ 左側沒有與其同色的數，則令 $C_i = 0$。
- 否則，記其左側**與其最靠近的同色數**為 $A_j$，若 $A_i = A_j$，則令 $C_i = A_i$，否則令 $C_i = 0$。

你的最終得分為 $C$ 中所有整數的和，即 $\sum \limits_{i=1}^n C_i$。你需要最大化最終得分，請求出最終得分的最大值。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

對於第一組資料，以下為三種可能的染色方案：

1. 將 $A_1, A_2$ 染成紅色，將 $A_3$ 染成藍色（$\red{1}\red{2}\blue{1}$），其得分計算方式如下：
- 對於 $A_1$，由於其左側沒有紅色的數，所以 $C_1 = 0$。
- 對於 $A_2$，其左側與其最靠近的紅色數為 $A_1$。由於 $A_1 \neq A_2$，所以 $C_2 = 0$。
- 對於 $A_3$，由於其左側沒有藍色的數，所以 $C_3 = 0$。    
該方案最終得分為 $C_1 + C_2 + C_3 = 0$。
2. 將 $A_1, A_2, A_3$ 全部染成紅色（$\red{121}$），其得分計算方式如下：
- 對於 $A_1$，由於其左側沒有紅色的數，所以 $C_1 = 0$。
- 對於 $A_2$，其左側與其最靠近的紅色數為 $A_1$。由於 $A_1 \neq A_2$，所以 $C_2 = 0$。
- 對於 $A_3$，其左側與其最靠近的紅色數為 $A_2$。由於 $A_2 \neq A_3$，所以 $C_3 = 0$。    
該方案最終得分為 $C_1 + C_2 + C_3 = 0$。
3. 將 $A_1, A_3$ 染成紅色，將 $A_2$ 染成藍色（$\red{1}\blue{2}\red{1}$），其得分計算方式如下：
- 對於 $A_1$，由於其左側沒有紅色的數，所以 $C_1 = 0$。
- 對於 $A_2$，由於其左側沒有藍色的數，所以 $C_2 = 0$。
- 對於 $A_3$，其左側與其最靠近的紅色數為 $A_1$。由於 $A_1 = A_3$，所以 $C_3 = A_3 = 1$。    
該方案最終得分為 $C_1 + C_2 + C_3 = 1$。

可以證明，沒有染色方案使得最終得分大於 $1$。

對於第二組資料，可以證明，任何染色方案的最終得分都是 $0$。

對於第三組資料，一種最優的染色方案為將 $A_1, A_2, A_4, A_5, A_7$ 染為紅色，將 $A_3, A_6, A_8$ 染為藍色（$\red{35}\blue{2}\red{51}\blue{2}\red{1}\blue{4}$），其對應 $C = [0, 0, 0, 5, 0, 2, 1, 0]$，最終得分為 $8$。
