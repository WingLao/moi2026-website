## Description · 題目說明

:::zh
對於一個城市來說，排水系統是極其重要的一個部分。

有一天，小 C 拿到了某座城市排水系統的設計圖。排水系統由 $n$ 個排水結點（它們從 $1 \sim n$ 編號）和若干個單向排水管道構成。每一個排水結點有若干個管道用於彙集其他排水結點的汙水（簡稱為該結點的彙集管道），也有若干個管道向其他的排水結點排出汙水（簡稱為該結點的排出管道）。

排水系統的結點中有 $m$ 個汙水接收口，它們的編號分別為 $1, 2, \ldots , m$，汙水只能從這些接收口流入排水系統，並且這些結點沒有彙集管道。排水系統中還有若干個最終排水口，它們將汙水運送到汙水處理廠，沒有排出管道的結點便可視為一個最終排水口。

現在各個汙水接收口分別都接收了 $1$ 噸汙水，汙水進入每個結點後，會均等地從當前結點的每一個排出管道流向其他排水結點，而最終排水口將把汙水排出系統。

現在小 C 想知道，在該城市的排水系統中，每個最終排水口會排出多少汙水。該城市的排水系統設計科學，管道不會形成迴路，即不會發生汙水形成環流的情況。
:::

## Input · 輸入格式

:::zh
第一個兩個用單個空格分隔的整數 $n, m$。分別表示排水結點數與接收口數量。  
接下來 $n$ 行，第 $i$ 行用於描述結點 $i$ 的所有排出管道。其中每行第一個整數 $d_i$ 表示其排出管道的數量，接下來 $d_i$ 個用單個空格分隔的整數 $a_1, a_2, \ldots , a_{d_i}$ 依次表示管道的目標排水結點。  
保證不會出現兩條起始結點與目標結點均相同的管道。
:::

## Output · 輸出格式

:::zh
輸出若干行，按照編號從小到大的順序，給出每個最終排水口排出的汙水體積。其中體積使用分數形式進行輸出，即每行輸出兩個用單個空格分隔的整數 $p$，$q$，表示排出的汙水體積為 $\frac{p}{q}$。要求 $p$ 與 $q$ 互素，$q = 1$ 時也需要輸出 $q$。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 #1 解釋】**

$1$ 號結點是接收口，$4, 5$ 號結點沒有排出管道，因此是最終排水口。  
$1$ 噸汙水流入 $1$ 號結點後，均等地流向 $2, 3, 5$ 號結點，三個結點各流入 $\frac{1}{3}$ 噸汙水。  
$2$ 號結點流入的 $\frac{1}{3}$ 噸汙水將均等地流向 $4, 5$ 號結點，兩結點各流入 $\frac{1}{6}$ 噸汙水。  
$3$ 號結點流入的 $\frac{1}{3}$ 噸汙水將均等地流向 $4, 5$ 號結點，兩結點各流入 $\frac{1}{6}$ 噸汙水。  
最終，$4$ 號結點排出 $\frac{1}{6} + \frac{1}{6} = \frac{1}{3}$ 噸汙水，$5$ 號結點排出 $\frac{1}{3} + \frac{1}{6} + \frac{1}{6} = \frac{2}{3}$ 噸汙水。

**【資料範圍】**

| 測試點編號 | $n \le$ | $m \le$ |
|:-:|:-:|:-:|
| $1 \sim 3$ | $10$ | $1$ |
| $4 \sim 6$ | ${10}^3$ | $1$ |
| $7 \sim 8$ | ${10}^5$ | $1$ |
| $9 \sim 10$ | ${10}^5$ | $10$ |

對於全部的測試點，保證 $1 \le n \le {10}^5$，$1 \le m \le 10$，$0 \le d_i \le 5$。

資料保證，汙水在從一個接收口流向一個最終排水口的過程中，不會經過超過 $10$ 箇中間排水結點（即接收口和最終排水口不算在內）。
:::
