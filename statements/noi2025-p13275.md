## Description · 題目說明

:::en
Little X has $2^n$ numbers $a_0, \ldots, a_{2^n - 1}$.

For $S \subseteq \{0, 1, \ldots, 2^n - 1\}$, $f(S)$ is the **bitwise AND of all elements of $S$** (the indices themselves); $f(\varnothing) = 2^n - 1$.

An ordered pair $(P, Q)$ of subsets (possibly empty) is **special** if $P \cap Q = \varnothing$ and $f(P) = f(Q)$. Its **weight** is $\prod_{i \in P \cup Q} a_i$ (empty product $= 1$).

Find the sum of the weights of all special pairs modulo $998{,}244{,}353$.
:::

:::zh
小 X 有 $2^n$ 個數，編號為 $0$ 到 $2^n - 1$，第 $i$ ($0 \leq i < 2^n$) 個數為 $a_i$。

對於 $S \subseteq \{0, 1, \ldots, 2^n - 1\}$，定義 $f(S)$ 為集合 $S$ 中 **所有數的二進位制按位與**。特別地，若 $S$ 為空集，則 $f(S) = 2^n - 1$。

定義兩個 $\{0, 1, \ldots, 2^n - 1\}$ 的子集 $P, Q$（可以為空）構成的有序對 $(P, Q)$ 是 **特別的** 當且僅當 $P \cap Q = \varnothing$ 且 $f(P) = f(Q)$。定義有序對 $(P, Q)$ 的 **權值** 為 **編號** 包含在 $P \cup Q$ 內的所有數的乘積，即 $\prod_{i \in P \cup Q} a_i$。特別地，若 $P \cup Q = \varnothing$，則有序對 $(P, Q)$ 的權值為 $1$。

小 X 想要知道所有特別的有序對的權值之和，請你幫助他求出這個值。由於答案可能較大，你只需要求出答案對 $998,244,353$ 取模後的結果。
:::
