## Description · 題目說明

:::en
Read some integers and print a list that contains the running total at each position.
:::

:::zh
讀入一些整數，輸出一個列表，列表中每個位置是到該位置為止的累加和。
:::

## Input · 輸入格式

:::en
One line of integers separated by spaces.
:::

:::zh
一行整數，以空格分隔。
:::

## Output · 輸出格式

:::en
One line: the list of running totals in Python format.
:::

:::zh
一行：Python 格式的累加和列表。
:::

## Sample Input · 範例輸入

```text
1 2 3 4
```

## Sample Output · 範例輸出

```text
[1, 3, 6, 10]
```

## Hints · 提示

:::en
- Keep a running total and append it after adding each number.
:::

:::zh
- 用一個變數記住目前總和，每加一個數就把總和加入列表。
:::

## Constraints · 限制

:::en
- Language: Python 3 or C++17.
- Your output must match the sample output exactly, including labels such as `Sum:` and every space.
:::

:::zh
- 語言：Python 3 或 C++17。
- 輸出必須和範例輸出完全一樣，包括 `Sum:` 之類的標籤和每一個空格。
:::
