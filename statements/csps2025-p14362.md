## Description · 題目說明

:::zh
C 國的交通系統由 $n$ 座城市與 $m$ 條連線兩座城市的雙向道路構成，第 $i$ ($1 \leq i \leq m$) 條道路連線城市 $u_i$ 和 $v_i$。**任意兩座城市都能透過若干條道路相互到達。**

然而，近期由於一場大地震，所有 $m$ 條道路都被破壞了，修復第 $i$ ($1 \leq i \leq m$) 條道路的費用為 $w_i$。與此同時，C 國還有 $k$ 個準備進行城市化改造的鄉鎮。對於第 $j$ ($1 \leq j \leq k$) 個鄉鎮，C 國對其進行城市化改造的費用為 $c_j$。在城市化改造完第 $j$ ($1 \leq j \leq k$) 個鄉鎮後，可以在這個鄉鎮與原來的 $n$ 座城市間建造若干條道路，其中在它與第 $i$ ($1 \leq i \leq n$) 座城市間建造一條道路的費用為 $a_{j,i}$。C 國可以在這 $k$ 個鄉鎮中選擇**任意多個**進行城市化改造，也可以不選擇任何鄉鎮進行城市化改造。

為儘快恢復城市間的交通，C 國政$ $府希望以最低的費用將**原有**的 $n$ 座城市兩兩連通，也即任意兩座原有的城市都能透過若干條修復或新建造的道路相互到達。你需要幫助他們求出，將原有的 $n$ 座城市兩兩連通的最小費用。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含三個非負整數 $n, m, k$，分別表示原有的城市數量、道路數量和準備進行城市化改造的鄉鎮數量。

輸入的第 $i+1$ ($1 \leq i \leq m$) 行包含三個非負整數 $u_i, v_i, w_i$，表示第 $i$ 條道路連線的兩座城市與修復該道路的費用。

輸入的第 $j+m+1$ ($1 \leq j \leq k$) 行包含 $n+1$ 個非負整數 $c_j, a_{j,1}, a_{j,2}, \ldots, a_{j,n}$，分別表示將第 $j$ 個鄉鎮進行城市化改造的費用與在該鄉鎮與原有的城市間建造道路的費用。
:::

## Output · 輸出格式

:::zh
輸出一行一個非負整數，表示將原有的 $n$ 座城市兩兩連通的最小費用。
:::
