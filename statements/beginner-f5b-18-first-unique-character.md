## Description · 題目說明

:::en
Read a string and print the index of the first character that appears only once.
:::

:::zh
讀入一個字串，輸出第一個只出現一次的字元的位置（索引）。
:::

## Input · 輸入格式

:::en
One line with a string.
:::

:::zh
一行，一個字串。
:::

## Output · 輸出格式

:::en
One integer: the index (starting from 0).
:::

:::zh
一個整數：索引（由 0 開始）。
:::

## Sample Input · 範例輸入

```text
leetcode
```

## Sample Output · 範例輸出

```text
0
```

## Hints · 提示

:::en
- First count every character, then scan the string from left to right.
:::

:::zh
- 先數好每個字元出現的次數，再由左至右掃描字串。
:::

## Constraints · 限制

:::en
- Language: Python 3 or C++17.
- Your output must match the sample output exactly, including labels such as `Sum:` and every space.
:::

:::zh
- 語言：Python 3 或 C++17。
- 輸出必須和範例輸出完全一樣，包括 `Sum:` 之類的標籤和每一個空格。
:::
