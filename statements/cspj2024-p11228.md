## Description · 題目說明

:::en
A robot explores a jungle map of $n$ rows and $m$ columns; $(i, j)$ is row $i$, column $j$. Character $\tt x$ is an obstacle and $\tt .$ is free.

The robot has a position $(x, y)$ and a direction $d$: $0$ east, $1$ south, $2$ west, $3$ north. It starts at $(x_0, y_0)$ (guaranteed free) facing $d_0$, and performs $k$ operations. Each operation:

1. The next cell $(x', y')$ is $(x, y+1)$, $(x+1, y)$, $(x, y-1)$ or $(x-1, y)$ for $d = 0, 1, 2, 3$.
2. If $(x', y')$ is inside the map and free, the robot moves there (same direction). Otherwise it turns right: $d' = (d + 1) \bmod 4$, staying in place.

After $k$ operations, how many different cells has the robot visited (including the start)?
:::

:::zh
小 A 打算前往一片叢林去探險。叢林的地理環境十分複雜，為了防止迷路，他先派遣了一個機器人前去探路。

叢林的地圖可以用一個 $n$ 行 $m$ 列的字元表來表示。我們將第 $i$ 行第 $j$ 列的位置的座標記作 $(i, j)(1 \leq i \leq n$，$1 \leq j \leq m)$。如果這個位置的字元為 $\tt x$，即代表這個位置上有障礙，不可透過。反之，若這個位置的字元為 $\tt.$，即代表這個位置是一片空地，可以透過。

這個機器人的狀態由位置和朝向兩部分組成。其中位置由座標 $(x, y)(1 \leq x \leq n$，$1 \leq y \leq m)$ 刻畫，它表示機器人處在地圖上第 $x$ 行第 $y$ 列的位置。而朝向用一個 $0 \sim 3$ 的整數 $d$ 表示，其中 $d = 0$ 代表向東，$d = 1$ 代表向南，$d = 2$ 代表向西，$d = 3$ 代表向北。

初始時，機器人的位置為 $(x_0, y_0)$，朝向為 $d_0$。**保證初始時機器人所在的位置為空地**。接下來機器人將要進行 $k$ 次操作。每一步，機器人將按照如下的模式操作：

1. 假設機器人當前處在的位置為 $(x, y)$，朝向為 $d$。則它的方向上的下一步的位置 $(x^′, y^′)$ 定義如下：若 $d = 0$，則令 $(x^′, y^′) = (x, y + 1)$，若 $d = 1$，則令 $(x^′, y^′) = (x + 1, y)$，若 $d = 2$，則令 $(x^′, y^′) = (x, y - 1)$，若 $d = 3$，則令 $(x^′, y^′) = (x - 1, y)$。

2. 接下來，機器人判斷它下一步的位置是否在地圖內，且是否為空地。具體地說，它判斷 $(x^′, y^′)$ 是否滿足 $1 \leq x^′ \leq n, 1 \leq y^′ \leq m$，且 $(x^′, y^′)$ 位置上是空地。如果條件成立，則機器人會向前走一步。它新的位置變為 $(x^′, y^′)$，且朝向不變。如果條件不成立，則它會執行“向右轉”操作。也就是說，令 $d^′ = (d + 1) \bmod 4$（即 $d + 1$ 除以 $4$ 的餘數），且它所處的位置保持不變，但朝向由 $d$ 變為 $d^′$。

小 A 想要知道，在機器人執行完 $k$ 步操作之後，地圖上所有被機器人經過的位置（包括起始位置）有幾個。
:::

## Input · 輸入格式

:::en
**Multiple test cases.** Line 1: a positive integer $T$.

Each case: a line with $n, m, k$; a line with $x_0, y_0$ and $d_0$; then $n$ lines of length $m$ made of $\tt x$ and $\tt .$.
:::

:::zh
**本題有多組測試資料。**

輸入的第一行包含一個正整數 $T$，表示資料組數。

接下來包含 $T$ 組資料，每組資料的格式如下：

第一行包含三個正整數 $n, m, k$。其中 $n, m$ 表示地圖的行數和列數，$k$ 表示機器人執行操作的次數。

第二行包含兩個正整數 $x_0, y_0$ 和一個非負整數 $d_0$。

接下來 $n$ 行，每行包含一個長度為 $m$ 的字串。保證字串中只包含 $\tt{x}$ 和 $\tt{.}$ 兩個字元。其中，第 $x$ 行的字串的第 $y$ 個字元代表的位置為 $(x, y)$。這個位置是 $\tt{x}$ 即代表它是障礙，否則代表它是空地。資料保證機器人初始時所在的位置為空地。
:::

## Output · 輸出格式

:::en
For each case, one line: the number of cells visited (including the start).
:::

:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

該樣例包含兩組資料。對第一組資料，機器人的狀態以如下方式變化：
1. 初始時，機器人位於位置 $(1, 1)$，方向朝西（用數字 $2$ 代表）。
2. 第一步，機器人發現它下一步的位置 $(1, 0)$ 不在地圖內，因此，它會執行“向右轉”操作。此時，它的位置仍然為 $(1, 1)$，但方向朝北（用數字 $3$ 代表）。
3. 第二步，機器人發現它下一步的位置 $(0, 1)$ 不在地圖內，因此，它仍然會執行“向右轉”操作。此時，它的位置仍然為 $(1, 1)$，但方向朝東（用數字 $0$ 代表）。
4. 第三步，機器人發現它下一步的位置 $(1, 2)$ 在地圖內，且為空地。因此，它會向東走一步。此時，它的位置變為 $(1, 2)$，方向仍然朝東。
5. 第四步，機器人發現它下一步的位置 $(1, 3)$ 在地圖內，且為空地。因此，它會向東走一步。此時，它的位置變為 $(1, 3)$，方向仍然朝東。

因此，四步之後，機器人經過的位置有三個，分別為 $(1, 1),(1, 2),(1, 3)$。

對第二組資料，機器人依次執行的操作指令為：向東走到 $(1, 2)$，向東走到 $(1, 3)$，向東走到 $(1, 4)$，向東走到 $(1, 5)$，向右轉，向南走到 $(2, 5)$，向南走到 $(3, 5)$，向南走到 $(4, 5)$，向南走到 $(5, 5)$，向右轉，向西走到 $(5, 4)$，向西走到 $(5, 3)$，向西走到 $(5, 2)$，向右轉，向北走到 $(4, 2)$，向右轉，向右轉，向南走到 $(5, 2)$，向右轉，向右轉。
