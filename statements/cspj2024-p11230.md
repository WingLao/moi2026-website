## Description · 題目說明

:::zh
在玩慣了成語接龍之後，小 J 和他的朋友們發明了一個新的接龍規則。

總共有 $n$ 個人參與這個接龍游戲，第 $i$ 個人會獲得一個整數序列 $S_i$ 作為他的詞庫。

一次遊戲分為若干輪，每一輪規則如下：

- $n$ 個人中的某個人 $p$ 帶著他的詞庫 $S_p$ 進行接龍。若這不是遊戲的第一輪，那麼這一輪進行接龍的人不能與上一輪相同，但可以與上上輪或更往前的輪相同。
- 接龍的人選擇一個長度在 $[2, k]$ 的 $S_p$ 的連續子序列 $A$ 作為這一輪的**接龍序列**，其中 $k$ 是給定的常數。若這是遊戲的第一輪，那麼 $A$ 需要以元素 $1$ 開頭，否則 $A$ 需要以上一輪的接龍序列的最後一個元素開頭。
  - 序列 $A$ 是序列 $S$ 的連續子序列當且僅當可以透過刪除 $S$ 的開頭和結尾的若干元素（可以不刪除）得到 $A$。

為了強調合作，小 J 給了 $n$ 個參與遊戲的人 $q$ 個任務，第 $j$ 個任務需要這 $n$ 個人進行一次遊戲，在這次遊戲裡進行恰好 $r_j$ 輪接龍，且最後一輪的接龍序列的最後一個元素恰好為 $c_j$。為了保證任務的可行性，小 J 請來你判斷這 $q$ 個任務是否可以完成的，即是否存在一個可能的遊戲過程滿足任務條件。
:::

## Input · 輸入格式

:::zh
**本題有多組測試資料。**

輸入的第一行包含一個正整數 $T$，表示資料組數。

接下來包含 $T$ 組資料，每組資料的格式如下：

第一行包含三個整數 $n, k, q$，分別表示參與遊戲的人數、接龍序列長度上限以及任務個數。

接下來 $n$ 行：

第 $i$ 行包含 $(l_i + 1)$ 個整數 $l_i, S_{i,1}, S_{i,2}, \dots , S_{i,l_i}$，其中第一個整數 $l_i$ 表示序列 $S_i$ 的長度，接下來 $l_i$ 個整數描述序列 $S_i$。

接下來 $q$ 行：

第 $j$ 行包含兩個整數 $r_j, c_j$，描述一個任務。
:::

## Output · 輸出格式

:::zh
對於每個任務：輸出一行包含一個整數，若任務可以完成輸出 1，否則輸出 0。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

在下文中，我們使用 $\{A_i\} = \{A_1, A_2, \dots , A_r\}$ 表示一輪遊戲中所有的接龍序列，$\{p_i\} = \{p_1, p_2, \dots , p_r\}$ 表示對應的接龍的人的編號。由於所有字元均為一位數字，為了方便我們直接使用數字字串表示序列。

- 對於第一組詢問，$p_1 = 1$、$A_1 = 12$ 是一個滿足條件的遊戲過程。
- 對於第二組詢問，可以證明任務不可完成。注意 $p_1 = 1$、$A_1 = 1234$ 不是合法的遊戲過程，因為此時 $|A_1| = 4 > k$。
- 對於第三組詢問，$\{p_i\} = \{2, 1\}$、$\{A_i\} = \{12, 234\}$ 是一個滿足條件的遊戲過程。
- 對於第四組詢問，可以證明任務不可完成。注意 $\{p_i\} = \{2, 1, 1\}、\{A_i\} = \{12, 23, 34\}$ 不是一個合法的遊戲過程，因為儘管所有的接龍序列長度均不超過 $k$，但第二輪和第三輪由同一個人接龍，不符合要求。
- 對於第五組詢問，$\{p_i\} = \{1, 2, 3, 1, 2, 3\}$、$\{A_i\} = \{12, 25, 51, 12, 25, 516\}$ 是一個滿足條件的遊戲過程。
-  對於第六組詢問，可以證明任務不可完成。注意每個接龍序列的長度必須大於等於 $2$，因此 $A_1 = 1$ 不是一個合法的遊戲過程。
- 對於第七組詢問，所有人的詞庫均不存在字元 $\tt 7$，因此任務顯然不可完成。
