## Description · 題目說明

:::zh
有一天小 S 和她的朋友小 N 一起研究一棵包含了 $n$ 個結點的樹。

這是一棵有根樹，根結點編號為 $1$，每個結點 $u$ 的深度 $\text{dep}_ u$ 定義為 $u$ 到 $1$ 的簡單路徑上的**結點數量**。

除此之外，再定義 $\text{LCA*}(l, r)$ 為編號在 $[l, r]$ 中所有結點的最近公共祖先，即 $l, l + 1, \dots , r$ 的公共祖先結點中深度最大的結點。

小 N 對這棵樹提出了 $q$ 個詢問。在每個詢問中，小 N 都會給出三個引數 $l, r, k$，表示他想知道 $[l, r]$ 中任意長度大於等於 $k$ 的連續子區間的最近公共祖先深度的最大值，即

$$\max_{l\le l'\le r'\le r \land r'-l'+1\ge k}\text{dep}_ {\text{LCA*}(l', r')}$$

你的任務是幫助小 S 來回答這些詢問。
:::

## Input · 輸入格式

:::zh
輸入的第一行包含一個正整數 $n$，表示樹的結點數。

接下來 $n - 1$ 行，每行包含兩個正整數 $u, v$，表示存在一條從結點 $u$ 到結點 $v$ 的邊。

第 $n + 1$ 行包含一個正整數 $q$，表示詢問的數量。

接下來 $q$ 行，每行包含三個正整數 $l, r, k$，描述了一次詢問。
:::

## Output · 輸出格式

:::zh
對於每次詢問輸出一行，包含一個整數，表示對應的答案。
:::

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

![圖 3](https://cdn.luogu.com.cn/upload/image_hosting/ktoq3ogh.png)

+ 對於第一組詢問，$\text{LCA*}(2, 3) = 2, \text{LCA*}(3, 4) = 2, \text{LCA*}(4, 5) = 6$，$2$ 的深度為 $3$，$6$ 的深度為 $2$，因此答案為 $\max\{3, 3, 2\} = 3$。

+ 對於第二組詢問，答案為 $1, 2, 3, 4$ 四個結點的最大深度，因此答案為 $4$。

+ 對於第三組詢問，$\text{LCA*}(1, 3) = 1, \text{LCA*}(2, 4) = 2, \text{LCA*}(3, 5) = 6, \text{LCA*}(4, 6) = 6$，依舊是 $2$ 的深度最大，因此答案為 $3$。
