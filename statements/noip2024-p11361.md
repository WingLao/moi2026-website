## Description · 題目說明

:::zh
小 M 有兩個長度為 $n$ 且字符集為 $\{0, 1\}$ 的字串 $s_1, s_2$。

小 M 希望兩個字串中對應位置字元相同的出現次數儘可能多，即滿足 $s_{1,i} = s_{2,i}$ 的 $i(1 \leq i \leq n)$ 儘可能多。為此小 M 有一個字串編輯工具，這個工具提供的基本操作是在一個字串中交換兩個**相鄰**的字元。為了保持字串的可辨識性，規定兩個字串中的部分字元不能參與交換。小 M 可以用工具對 $s_1$ 或 $s_2$ 進行多次字元交換，其中可以參與交換的字元能夠交換任意多次。

現在小 M 想知道，在使用編輯工具後，兩個字串中對應位置字元相同的出現次數最多能有多少。
:::

## Input · 輸入格式

:::zh
**本題包含多組測試資料。**

輸入的第一行包含一個整數 $T$，表示測試資料的組數。

接下來包含 $T$ 組資料，每組資料的格式如下：

- 第一行包含一個整數 $n$，表示字串長度。
- 第二行包含一個長度為 $n$ 且字符集為 $\{0, 1\}$ 的字串 $s_1$。
- 第三行包含一個長度為 $n$ 且字符集為 $\{0, 1\}$ 的字串 $s_2$。
- 第四行包含一個長度為 $n$ 且字符集為 $\{0, 1\}$ 的字串 $t_1$，其中 $t_{1,i}$ 為 $1$ 表示 $s_{1,i}$ 可以參與交換，$t_{1,i}$ 為 $0$ 表示 $s_{1,i}$ 不可以參與交換。
- 第五行包含一個長度為 $n$ 且字符集為 $\{0, 1\}$ 的字串 $t_2$，其中 $t_{2,i}$ 為 $1$ 表示 $s_{2,i}$ 可以參與交換，$t_{2,i}$ 為 $0$ 表示 $s_{2,i}$ 不可以參與交換。
:::

對於每組測試資料輸出一行，包含一個整數，表示對應的答案。

## Notes and Constraints · 說明與數據範圍

:::zh
**【樣例 1 解釋】**

最開始時，$s_1 = \tt{011101}$，第 $4$ 和第 $6$ 個字元不能參與交換；$s_2 = \tt{111010}$，第 $2$ 和第 $5$ 個字元不能參與交換。

考慮如下操作：先交換 $s_{1,1}$ 與 $s_{1,2}$ 得到 $s_1 = \tt{101101}$，再交換 $s_{1,2}$ 與 $s_{1,3}$ 得到 $s_1 = \tt{110101}$，最後交換 $s_{2,3}$ 與 $s_{2,4}$ 得到 $s_2 = \tt{110110}$。此時 $s_1$ 與 $s_2$ 的前 $4$ 個位置上的字元都是相同的。可以證明不存在更好的方案，故輸出 $4$。

**【樣例 2 解釋】**

見附件的 edit/edit2.in 與 edit/edit2.ans。

該樣例共有 $10$ 組測試資料，其中第 $i(1 \leq i \leq 10)$ 組測試資料滿足資料範圍中描述的測試點 $2i - 1$ 的限制。

**【資料範圍】**

對於所有的測試資料，保證：$1 \leq T \leq 10$，$1 \leq n \leq 10^5$。

::cute-table{tuack}

| 測試點編號 | $n\leq$ | 特殊性質 |
| :----------: | :----------: | :----------: |
| $1\sim 4$ | $10$ | 無 |
| $5,6$ | $10^3$ | A |
| $7,8$ | $10^5$ | ^ |
| $9,10$ | $10^3$ | B |
| $11,12$ | $10^5$ | ^ |
| $13,14$ | $10^3$ | C |
| $15,16$ | $10^5$ | ^ |
| $17,18$ | $10^3$ | 無 |
| $19,20$ | $10^5$ | ^ |


- 特殊性質 A：保證 $s_1$ 的所有字元相同。
- 特殊性質 B：保證 $t_1 = t_2$。
- 特殊性質 C：保證 $t_1$ 和 $t_2$ 中各自恰有一個字元  $\tt 0$。
:::
