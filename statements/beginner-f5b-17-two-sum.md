## Description · 題目說明

:::en
Read a list of integers and a target. Print the two indices whose numbers add up to the target.
:::

:::zh
讀入一列整數和一個目標值，輸出兩個位置（索引），使這兩個位置上的數相加等於目標值。
:::

## Input · 輸入格式

:::en
Line 1: the integers, separated by spaces. Line 2: the target.
:::

:::zh
第 1 行：整數，以空格分隔。第 2 行：目標值。
:::

## Output · 輸出格式

:::en
One line: the two indices as a Python list, e.g. `[0, 1]`.
:::

:::zh
一行：兩個索引，以 Python 列表輸出，例如 `[0, 1]`。
:::

## Sample Input · 範例輸入

```text
2 7 11 15
9
```

## Sample Output · 範例輸出

```text
[0, 1]
```

## Hints · 提示

:::en
- Indices start from 0.
:::

:::zh
- 索引由 0 開始。
:::

## Constraints · 限制

:::en
- Language: Python 3 or C++17.
- Your output must match the sample output exactly, including labels such as `Sum:` and every space.
:::

:::zh
- 語言：Python 3 或 C++17。
- 輸出必須和範例輸出完全一樣，包括 `Sum:` 之類的標籤和每一個空格。
:::
